SpectralForge Chimera OBS 필터 — Linux x86_64 설치 / installation
=================================================================

[한국어]
필요: Chimera Linux VST3(~/.vst3, /usr/local/lib/vst3 또는 /usr/lib/vst3), 배포판 패키지로 설치한 OBS Studio.
Flatpak·Snap으로 설치한 OBS는 외부 플러그인 폴더를 읽지 않으므로 지원하지 않습니다.
glibc 2.38 이상(Ubuntu 24.04 수준)의 x86_64 배포판이 필요합니다. 모듈은 OBS의 libobs와 배포판의 libstdc++·libgcc_s를 사용합니다.

1. OBS를 종료합니다.
2. 이 폴더에서 ./install.sh 를 실행합니다(root 권한 불필요).
   ~/.config/obs-studio/plugins/chimera-obs 에 설치됩니다.
3. OBS를 시작하고 오디오 소스 → 필터 → SpectralForge Chimera를 추가합니다. 사용법은 README.txt.

제거: ./install.sh --uninstall (설치한 파일만 지우고, 그 폴더에 직접 넣은 파일과 OBS 장면은 그대로 둡니다).
이 모듈은 Ubuntu 24.04의 libobs 30.0.2로 빌드·시험했습니다. 다른 OBS 버전에서는 OBS 로그의
"[chimera-obs] module" 줄에 실행 중인 OBS 버전이 함께 나옵니다.

[English]
Requires the Chimera Linux VST3 (~/.vst3, /usr/local/lib/vst3 or /usr/lib/vst3) and OBS Studio from your
distribution's packages. Flatpak and Snap builds of OBS do not read external plugin folders and are not supported.
Needs an x86_64 distribution with glibc 2.38 or newer (Ubuntu 24.04 level); the module uses OBS's libobs and the
distribution's libstdc++ and libgcc_s.
Close OBS, run ./install.sh (no root needed; installs to ~/.config/obs-studio/plugins/chimera-obs), start OBS,
then add Filters → SpectralForge Chimera to an audio source. Remove with ./install.sh --uninstall, which deletes
only the installed files. Built and tested with libobs 30.0.2 (Ubuntu 24.04).

[설치 보호 / Installation safety]
네이티브 설치 프로그램이 포함되어 있어 Python이나 컴파일러를 따로 설치할 필요가 없습니다. root로 실행하지 마세요. 설치·제거가 끝날 때까지 OBS를 종료 상태로 유지하세요.
OBS 실행 여부 확인 실패도 설치·제거를 차단합니다. 후보 파일의 전체 목록·SHA-256·권한을 검사하고,
macOS에서는 번들 서명도 검사한 뒤 기존 설치와 원자 교체합니다. 지원하지 않는 파일시스템에서는 중단합니다.
오류·중단 시 기존 설치로 복구하며, 강제 종료(SIGKILL) 후에는 같은 스크립트를 다시 실행하면 복구합니다.
디스크 오류로 복구가 불가능하면 표시된 .chimera-obs-transaction 폴더를 보존하세요. 이전 설치 백업입니다.
빈 .chimera-obs-install.lock은 동시 설치 방지용으로 남습니다. OBS 장면·설정·다른 플러그인·Chimera VST3는 보존합니다.
macOS 번들 안에 사용자 파일을 추가했다면 업데이트 전에 밖으로 옮겨야 합니다. 제거 시에는 사용자 파일을 보존합니다.

The native installer is included. No Python or compiler installation is required. Do not run as root. Keep OBS closed until installation/removal finishes.
Unknown process state also blocks changes. Full payload SHA-256/inventory/permissions and macOS signatures are
checked before atomic replacement; unsupported filesystems fail without deleting the old installation.
Errors and catchable interruptions restore the previous copy. After SIGKILL, rerun this script to recover.
If disk errors prevent recovery, keep the reported .chimera-obs-transaction directory: it contains the backup.
An empty .chimera-obs-install.lock remains to serialize installers. Scenes, settings, other plugins and VST3 are preserved.
Move added user files out of a macOS bundle before updating; uninstall preserves them.
Checksums/ad-hoc signatures detect corruption; they do not establish publisher identity or Apple notarization.
