# Náströnd A2 출시 기준 v3, 2026-10-28

[English](release-profile-v3-20261028.md)

## 배경

기준 v2는 full ESR 0.01 미만, 연주 구간 ESR p95 0.01 이하, 최악값 0.02 이하를 요구합니다. 다음 두 가지 이유로 하이게인 채널은 TONE3000에서 이 기준에 닿을 수 없습니다.

- TONE3000은 너비 3 또는 8인 A2 모델만 불러옵니다([tone3000-a2-only-20261028](tone3000-a2-only-20261028.md)).
- 너비 8에서 쓸 수 있는 방법은 모두 시도했습니다([channel-loss-20261028](channel-loss-20261028.md)).
  - 시도한 것: 데이터 양, 학습량, 학습률 스케줄, 모델 기억 길이, 큰 음 위주 학습, 진폭·피크 가중, 손실 정규화.
  - 데이터 효과: 두 배로 늘릴 때마다 −3.6% 수준까지 줄었고, 테스트 평균 full ESR은 약 0.017에서 멈출 것으로 추정됩니다.
  - 모델 크기: TONE3000이 불러올 수 없는 너비 32 모델조차 구간 p95가 약 0.07이었습니다([capacity-diagnostic-20261026](capacity-diagnostic-20261026.md)).

오너는 TONE3000을 포기하는 대신 A2에 맞는 출시 기준을 새로 정하기로 했습니다.

## 바뀌는 점

v3(`quality_profile.py`의 `RELEASE_V3`)는 v2 옆에 추가한 출시 판정 기준입니다.

- **v2는 그대로 둡니다.** 원본 충실도를 보여 주는 기준으로 계속 함께 보고합니다.
- **측정 방법은 같습니다.** `fidelity()`의 v2 구간, 고정 기준 레벨, 입력 이력이 없는 샘플 처리 규칙을 그대로 씁니다.
- **바뀌는 것은 연주 구간과 full ESR 한도뿐이고, 채널 종류별로 다르게 정합니다.**

| 항목 | v2 | v3 하이게인 (Fenrir, Surtr, Nidhoggr, Ragnarok) | v3 블룸 (Fimbulvetr) |
|---|---:|---:|---:|
| Full ESR | < 0.01 | ≤ 0.025 | ≤ 0.01 |
| 연주 구간 중앙값 | ≤ 0.005 | ≤ 0.02 | ≤ 0.0075 |
| 연주 구간 p95 | ≤ 0.01 | ≤ 0.12 | ≤ 0.03 |
| 연주 구간 최악값 | ≤ 0.02 | ≤ 0.40 | ≤ 0.20 |
| 조용한 구간 잔차 RMS / 피크 | −70 / −60 dBFS | 동일 | 동일 |
| 레벨 RMS / 피크 | ±0.5 / ±1 dB | 동일 | 동일 |

규칙:

- **검증 신호와 학습에서 뺀 테스트 신호를 모두 통과해야 합니다.**
- **출시 승인에는 오너의 실제 악기 DI 청음 확인도 필요합니다.** 수치는 원본 DSP와 얼마나 다른지를 보여 줄 뿐, 실제 기타에서 그 차이가 들리는지는 알려 주지 않습니다.
- Fimbulvetr는 이미 v2의 full ESR 기준을 통과하므로 v3에서도 같은 기준을 유지합니다.

## 이 결정의 한계

- **결과를 본 뒤 정한 기준입니다.** 측정된 A2 한계를 근거로 정했기 때문에, "원본 DSP와 구별할 수 없다"는 보증이 아니라 "A2로 갈 수 있는 만큼 가까이 갔다"는 판정입니다.
- **여유가 작은 항목이 있습니다.**
  - 구간 최악값: Nidhoggr 테스트 0.376, 한도 0.40
  - 하이게인 full ESR: Nidhoggr 테스트 0.0224, 한도 0.025
- **조용한 구간과 레벨 기준은 완화하지 않았습니다.**

## 현재 패키지 세트 판정

현재 TONE3000 테스트 패키지에 들어 있는 세트입니다([tone3000-a2-only-20261028](tone3000-a2-only-20261028.md)).

| 채널 | 검증 | 테스트 | v3 수치 판정 |
|---|---|---|---|
| Fenrir | **조용한 구간 불합격** | 합격 | **불합격** |
| Surtr | 합격 | 합격 | 합격 |
| Nidhoggr | 합격 | 합격 | 합격 |
| Fimbulvetr | 합격 | 합격 | 합격 |
| Ragnarok | 합격 | 합격 | 합격 |

**Fenrir는 검증 신호에서 그대로 둔 조용한 구간 기준에 걸립니다.**

- **걸리는 구간:** 23.51초(시작 샘플 1,128,651)의 조용한 구간 하나입니다. 입력이 끝난 직후의 음 여운으로, 아직 모델의 기억 범위 안에 있습니다.
- **수치:** 잔차 RMS −70.8 dBFS(한도 −70), 피크 −53.3 dBFS(한도 −60)입니다.
- **이력:** 최근 다섯 번의 학습에서 검증한 Fenrir 체크포인트 280개 가운데 이 구간을 통과한 것은 하나도 없었습니다.
- **테스트 신호:** 조용한 구간 잔차는 −88.8 / −81.9 dBFS로 여유 있게 통과합니다.

청음 확인을 아직 하지 않았기 때문에 출시 승인된 채널은 아직 없습니다.
