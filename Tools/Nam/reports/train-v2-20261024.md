# Náströnd A2 v2 training, 2026-10-24

First run after the restart: five product channels captured from main
`4ef21c16` at their own defaults, quality profile
`nastrond-tone3000-fidelity-v2`. **Numerical accuracy: FAIL on all five.**
No release approval.

## Run

The capture uses the default 96/24/24/8-second synthetic protocol. Training ran
5,000 steps from scratch with the legacy recipe: batch 2, 2,048 frames,
LR 0.004 with a 2,000-step half-life, 10% terminal-decay crops and
export-consistent centering. It ran on 4 CPU threads in Python 3.12 with the
PyPI torch 2.8.0 build and trainer `0072676`, and took 27.6 minutes. The held-out
test split was not used; it stays reserved for a final candidate.

ESR limits, which every channel misses.

## Reading

- **Active audio is the blocker.** Every channel misses the active ESR limits by
  roughly an order of magnitude. The mean full ESR is 0.098, against 0.099 for
  the 2026-10-11 v1 baseline on the older DSP. The two runs used different DSP
  and a different profile, so this is context, not a comparison.
- **The v2 quiet rule did not decide any result here.** The zero-history
  residuals are −84.5 to −110.1 dBFS, far below the limits. Four channels pass
  quiet. Fenrir fails quiet on samples that do have input history, so that is a
  genuine model error, not the proven A2 limit.
- **Training had not converged.** The selection ESR still fell between steps
  4,500 and 5,000 for every channel, and four of the five selected their final
  step. The learning rate had already decayed to 0.0007.

## Reproduce

See `../README.md` ("Local build"). Then run
`capture_channels.py --train-seconds 96` and `train_a2.py` with the command in
`train-v2-20261024.json`. The models, checkpoint and capture arrays are kept
outside the repository.
