# Importing personal cabinet IRs

The public IR library includes the two attributed factory guitar recordings
listed in [IR_DISTRIBUTION.md](IR_DISTRIBUTION.md), alongside the files you
choose to import. Unapproved development capture catalogs and external-pack
download prompts are excluded from Open Beta 1.3.

## Add a file or folder

1. Open **IR LIBRARY** and choose **OPEN IR** for a WAV/AIFF file or
   **ADD FOLDER** for an existing personal library.
2. Keep the default **Import: keep existing type** to retain sidecar metadata.
   Choose **Import as: Bass**, **Guitar** or **Unspecified** when classification
   is needed.
3. Select an available recording and choose **LOAD INTO RIG**.

**Type** changes the classification of an imported entry. **REMOVE FROM LIST**
removes the entry from the browser without deleting the source file or the IR
already stored in a project/A/B state. **OPEN IR** can add that file again.

Chimera validates the selected audio. Unknown filenames do not inherit a
creator, source URL or license from an internal private collection. User
sidecars remain the source of any supplied capture information.

## Recall and sharing

The four cabinet-source automation values remain unchanged: Filters only,
V30, Jensen and User IR. Imported IR audio is stored in local project/preset
state for recall. Factory presets use the authored original CAB recipes and do
not search for specific personal recordings.

Keep the creator's terms with your own library and review them before sharing
a project or preset containing third-party audio. Importing a file does not
establish permission to redistribute it. Chimera does not download capture
packs automatically or upload personal IRs.
