# SpectralForge Chimera — 2026-09-28 수정 테스트 빌드

앞서 전달한 50271a6 후보에서 페달보드가 기본 비활성이고, 앰프 메뉴가 중복되며,
신규 앰프가 비활성 안내에만 머물렀던 문제를 수정하는 빌드입니다.
패키지 이름의 커밋과 build-manifest.json을 기준으로 구별하세요.

## 바로 확인되는 변경

- 새 인스턴스는 **최대 5슬롯 범용 PRE 보드**를 켠 상태로 PRE 화면에서 열립니다.
  빈 슬롯을 클릭해 어떤 지원 종류든 선택합니다. Bypass도 한 슬롯을 사용합니다.
  같은 모델을 독립적으로 복제하고 이동·교체·삭제·Undo/Redo·MIDI를 사용할 수 있습니다.
- 이전 프로젝트와 기존 factory preset은 원래 PRE 소리를 보존합니다.
  PRE 상단에 **LEGACY PRE ACTIVE**가 표시되고 새 카드의 편집은 비활성입니다.
  **USE NEW 5-SLOT BOARD**로 명시 전환합니다. **LEGACY CONTROLS**로 이전 조절부를 엽니다.
  엔진 전환은 원본 노브 위치와 이전 Hz/dB/ms를 자동 환산하지 않습니다.
- 6개 이하의 조절부는 페달 카드에 직접 표시합니다. M87의 5개 조절부와 밝은
  페달의 라벨 대비를 수정했습니다. 복잡한 모델은 같은 면적의 CONTROLS 화면을 사용합니다.
- 앰프 메뉴에는 **Chimera 모델명만** 표시합니다. Clean / Crunch / Lead /
  High-Gain / Bass의 한 분류에 모델마다 한 번만 나타납니다. 선택란·설명·툴팁에
  원본 앰프명을 붙이지 않습니다. 어느 레인에서도 모든 모델을 선택할 수 있습니다.
- 신규 8개를 포함해 **23개 앰프가 실제 오디오 경로에 연결**됩니다.
  Cinder 120, Iron Compact, Fourfold, Classic Tube, Monolith, Night Harvest,
  Hot Lead, Blue Storm을 선택할 수 있습니다. 신규 모델의 채널 또는 입력경로
  선택란도 연결됩니다. 자세한 알고리즘·참조 범위는 NEW_AMP_DSP.md를 확인하세요.
- 기존 15개 앰프의 host parameter 선택지 수와 정규화된 자동화는 유지합니다.
  신규 선택은 별도 구조 파라미터로 저장하고 이전 앰프 자동화가 새 선택을
  묵시적으로 해제하지 않습니다. 신규 모델의 채널 선택은 모델/레인별로 기억합니다.

## 오디오와 상태의 경계

새 앰프는 개별 비선형 경로·단간 결합·피드백·전원 응답을 가진 독립 실험 DSP입니다.
NAM 파일을 실행하거나 실물 회로·원본 노브 테이퍼를 검증한 결과가 아닙니다.
현재 DRIVE/EQ/LEVEL은 공통 소프트웨어 조절부입니다. 원본 앰프 v3의 모든
전용 노브·스위치·공유 EQ와 Classic/Dual/Matrix 6문맥의 완전한 패널 은행은
아직 연결되지 않았습니다. POST 9종의 원본 전용 패널도 Preparation 단계입니다.

단음·폴리 옥타버의 구현·추가 지연 및 품질 범위는 PEDAL_BOARD_DSP.md를 확인하세요.
실제 연주·하드웨어 비교와 Sonar/Cubase/Studio One의 종료 무응답은 별도 재현이 필요합니다.
빌드의 CTest.log는 자동 검증 기록이며 실제 사용자 DAW에서의 완료 승인은 아닙니다.

모델 선택/복제는 고정 host parameter 은행을 사용합니다. 동일 자리/모델의
이전 DAW 자동화가 다시 적용될 수 있어 선택 때 해당 은행 사용을 확인합니다.
이동은 소유자 ID를 보존합니다. 구조 편집과 LOW TAP 이동은 재생을 멈춘 뒤 하세요.

## 설치와 구분

1. 압축을 풀어 동봉된 EXE로 새 기본 PRE 화면과 23개 앰프를 먼저 확인합니다.
2. EXE 실행만으로 DAW의 VST3는 갱신되지 않습니다. DAW를 종료하고 이전 VST3를
   보관한 뒤 새 `SpectralForge Chimera.vst3` 폴더 전체를 교체하고 재검색합니다.
3. SETTINGS의 build 값이 패키지 커밋과 같은지 확인합니다. 사용자 IR은 유지합니다.
4. 기존 프로젝트는 복사본으로 열어 저장된 PRE 엔진·앰프·값·IR을 확인합니다.
5. 복귀할 때는 DAW를 종료하고 보관한 이전 VST3 폴더로 되돌립니다.

기존 beta1 릴리스 파일은 이 테스트 빌드로 덮어쓰지 않습니다.
