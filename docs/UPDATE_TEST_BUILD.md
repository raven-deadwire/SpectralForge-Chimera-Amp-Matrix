# SpectralForge Chimera — 2026-09-28 테스트 업데이트

10월 1일 예약의 누적 범위를 앞당겨 진행하는 업데이트 후보입니다.
파일명이나 UI의 Beta 1.0 표기만으로 전체 요청 완료를 뜻하지 않습니다.
해당 커밋의 CI·검증 기록·실제 Windows 패키지를 기준으로 사용하세요.

## 실제 제품 코드에 연결된 범위

- 선택형 `UNIVERSAL 5 / EXPERIMENTAL`: 최대 다섯 인스턴스의 PRE, 모델별
  조절부, 배치 이동/교체/복제/삭제, 상세 편집, Undo/Redo, MIDI 학습,
  모델별 값·Bypass·순서·LOW TAP의 APVTS 상태 저장을 추가했습니다.
  실험 DSP와 Legacy PRE는 명시적으로 전환하며 원본 노브 위치와 기존
  Hz/dB/ms 값을 자동 환산하지 않습니다. 비활성 컨트롤은 미구현입니다.
- 같은 다섯 페달 사이의 LOW TAP을 Matrix 분기에 사용합니다. TAP 앞의
  왜곡은 LOW에도 적용됩니다. Classic/Dual은 같은 순서의 직렬 PRE입니다.
- 기존 15개 앰프에 겹치는 Clean/Crunch/Lead/High-Gain/Bass와 Guitar/Bass
  탐색 메뉴를 추가했습니다. 이름·raw index·호스트 선택지 개수는 유지하며
  모든 레인에서 교차 선택할 수 있습니다. 태그는 원본 채널 추가가 아닙니다.
- `POST GATE`는 깨끗한 입력 검출과 리그 합산 뒤 감쇄를 분리합니다.
  POST Delay/Reverb 앞에서 감쇄하므로 공간계의 기존 잔향 경로를 유지합니다.
- `SETTINGS → Review / copy / save diagnostics...`는 다섯 단계의 마지막 블록 RMS/Peak,
  보고 지연·모드·Transpose·오버샘플링·콜백 부하를 제공합니다. LUFS/전체 PC CPU가
  아니며 오디오 파일을 포함하지 않습니다. 전역 +10 dB 보정은 하지 않았습니다.
- Editor/Timer/비동기 다이얼로그 수명, Transpose의 0반음/블록 경계,
  compressor GR 측정과 경로를 보강했습니다. 실제 DAW 제보의 원인 확정과
  해결 승인은 Windows 환경의 재현 기록을 별도로 요구합니다.

| 항목 | 현재 경계 |

| 필수/권고 앰프 8개 | ZUTA/ENGL/Diezel/SVT-CL/SUNN 및 Fortin/Soldano/Bogner는 비활성 개발 안내만 표시. 신규 DSP 선택값 없음 |
| POST R1a | 컴프·프리앰프·EQ 9종 원본 패널과 `.crlab` 구현. 제품의 POST 파라미터/DSP로 연결되지 않음 |
| 옥타버 및 일부 원본 기능 | 단음/폴리 옥타버, 일부 Manley 독립 스테레오 제어, AW-3 HUMAN/TEMPO 등 비활성·개발 대기 |

모델 선택/복제 시 고정 호스트 파라미터 은행 사용을 확인합니다. 같은 자리와
같은 모델의 옛 DAW 자동화는 다시 적용될 수 있습니다. A/B 사용기록과 독립적으로
모든 선택/복제에서 안내합니다. 실험 보드에서 모델을 교체하거나 삭제하면 그 인스턴스에 남아 있는 자동화와
MIDI 의도를 확인하세요. 보드의 고정 호스트 소유자와 모델별 파라미터가
표시 순서와 구분되지만, 모든 DAW의 실시간 자동화 동작까지 검증된 것은 아닙니다.

## 검증 상태의 구분

- 준비 기준 `68ae655`: 독립 clean 작업 공간에서 158개 통과, Chromium
  부재로 브라우저 44개 미실행. 기존 202개 전체 통과를 이번 실행에 재사용하지
  않았습니다. 이 결과만으로 제품 CP0를 발급하지 않습니다.
- R1a 수정 후: 204개 비브라우저 검사 통과, 기존44+신규12=56개 브라우저
  미실행. 필수 실행 명령은 `Preparation/run_checks.py --require-browser`이며
  브라우저 부재는 종료코드 2, `blocked_environment`입니다.
- 제품 native DSP/UI/상태 검사는 별도의 테스트 실행 로그를 기준으로 합니다.
  테스트 소스 추가, CI 실행 시작, CI 성공, Windows 다운로드 가능, 실제 DAW
  실행은 각각 별도 상태입니다. 본 문서에는 실행 전 성공 수치를 채우지 않습니다.
- 복구 도구 REC-01b/01c 검증 역시 제품 소리·Windows 검증을 대체하지 않습니다.

## Windows에서 확인할 순서

1. 테스트 패키지의 정확한 리비전과 VST3/Standalone 파일을 확인합니다.
   기존 프로젝트는 복사본으로 열고 Legacy PRE의 모델·순서·값·IR을 먼저
   확인합니다. 사용자 IR 공유 조건은 그대로 유지합니다.
2. UI 미개방/1회 개방/반복 개폐를 구분해 플러그인 제거, 프로젝트 닫기,
   DAW 종료를 각각 재현합니다. Sonar/Cubase/Studio One의 결과를 섞지 않고
   멈춘 단계와 로그/덤프를 남깁니다.
3. 같은 스템에서 Legacy와 Experimental, Classic/Dual/Matrix 및
   Gate/Transpose/OS를 하나씩 바꾸고 진단 RMS/Peak와 콜백 부하를 비교합니다.
   크게 들리는 설정을 더 정확한 재현으로 판정하지 않습니다.
4. 다섯 자리 제한, 동일 모델 두 개의 독립 조절, 이동 후 자동화/MIDI,
   TAP 앞뒤 이동, Bypass, 저장·재개, A/B를 확인합니다. 미연결 컨트롤은
   비활성이어야 합니다.
5. 실제 DI/연주, 저음 보존·DI/AMP 합산, 피치 아티팩트와 잔향을 별도로
   청취합니다. 합성 입력 검사 결과를 연주 검증 완료로 기록하지 않습니다.

공개 릴리스/자동 업데이트 등록은 테스트 패키지와 별도입니다. 미완료
모델·채널·자산·플랫폼 범위는 다음 구현 항목으로 유지합니다.
