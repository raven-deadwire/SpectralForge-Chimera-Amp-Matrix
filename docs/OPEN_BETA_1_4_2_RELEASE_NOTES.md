# SpectralForge Chimera — Open Beta 1.4.2

**Version 1.4.2-beta.1 · Windows / macOS / Linux · 공개 베타**

공개된 1.4.1-beta.1(2026-11-18 KST) 이후 main에 통합된 작업을 묶은 베타입니다. 만료일은 1.4.0-beta.1, 1.4.1-beta.1과 같은 **2027-05-31 23:59 KST**입니다. 이 소스 그대로의 Windows·macOS·Linux 자동 검증을 통과하고, 아래 알려진 한계를 공개한 상태로 소유자가 공개를 승인해야 공개됩니다([후보 기록](RELEASE_1_4_2_CANDIDATE.md)). 안정판이나 엄격 검증 통과가 아닙니다.

모델 카탈로그(AMP 30, PRE 51, POST 39, CREATIVE 9, SYNTH 3), 파라미터와 저장 형식은 1.4.1-beta.1과 같습니다. 자동 시험은 실제 악기 DI·DAW·청음 검증을 대신하지 않습니다.

## 주요 변경

### Auto Set (새 단계는 모두 기본 꺼짐)

새 단계 10개는 AUTO SET 옆 옵션 버튼에서 켭니다. DI·청음 확인을 아직 거치지 않아 기본값은 꺼짐이며, 켜지 않으면 Auto Set 결과는 1.4.1-beta.1과 같습니다. 각 단계는 잠금·강도·UNDO AUTO를 따릅니다. 지금까지 Classic 라우팅에서만 하던 앰프 설정을 Dual 라우팅의 두 리그와 Matrix 라우팅의 MID·HIGH 레인으로 넓힙니다.

**Dual Blend의 두 리그**

- **앰프 게인과 톤 (33단계):** 리그마다 따로 듣는 패스가 추가되어 듣는 시간이 늘어납니다.
- **Presence와 Resonance (34단계):** 각 리그의 게인·톤 단계 뒤에 실행합니다.
- **앰프 채널 선택 (35단계):** 각 리그 패스의 맨 앞에서 실행합니다.
- **GAIN 범위를 넘는 입력 트림 (36단계):** 각 리그의 게인·톤 단계 뒤, Presence 단계 앞에서 실행합니다.

**Dual Crossover의 두 리그**

- **앰프 게인 (37단계):** 리그마다 따로 듣는 패스가 추가됩니다.
- **앰프 채널 선택 (38단계):** 각 리그의 게인 단계 앞에서 실행합니다.
- **입력 트림 (39단계):** 각 리그의 게인 단계 뒤에서 실행합니다.

**Matrix의 MID·HIGH 레인**

- **앰프 게인 (40단계):** 레인마다 따로 듣는 패스가 추가됩니다.
- **앰프 채널 선택 (41단계):** 각 레인의 게인 단계 앞에서 실행합니다.
- **입력 트림 (42단계):** 각 레인의 게인 단계 뒤에서 실행합니다.

34·35·36단계, 38·39단계, 41·42단계는 자기 패스가 따로 없습니다. 하나만 켜도 두 리그(레인) 패스가 시작됩니다. 자세한 규칙은 `docs/AUTO_SET_PHASE33.md` … `docs/AUTO_SET_PHASE42.md`에 있습니다.

### 시험과 CI (제품 동작 변화 없음)

- 실제 OBS 앱 시험 두 개가 macOS CI 러너의 타이밍 때문에 떨어지던 것을 손봤습니다. OBS 필터 코드는 1.4.1-beta.1과 같습니다.
- 프리셋 유지보수 도구가 고정해 두는 튜너 시험 파일의 다이제스트를 소유자 승인으로 다시 등록했습니다.
- 저장소 문서: AAX·Windows 배포 서명 안내서와 OBS 필터 테스트 안내서를 추가했습니다(제품 변화 없음).

## 알려진 한계

1.4.1-beta.1의 한계가 그대로 남아 있습니다.

- 실제 기타·베이스 DI 청음과 Drop A 테이크 검증은 하지 않았습니다.
- 실제 DAW·오디오 장치 수용 시험은 하지 않았습니다.
- 퍼블리셔 서명과 macOS 공증은 없습니다.
- Pro Tools의 AAX는 검증하지 않았습니다.
- 1.4.1의 새 Auto Set 단계 7개와 이번의 10개는 합성 신호 시험만 거쳤습니다.
- 새 독일어·한국어 설명서 문구의 원어민 검토가 남아 있습니다.

실행하지 않은 검사는 통과로 보고하지 않습니다.
