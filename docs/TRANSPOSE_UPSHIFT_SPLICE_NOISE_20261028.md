# 업시프트 접합 잡음 연구 — 2026-10-28 KST

**배경.** 44.1kHz 약한 마커 분석(`TRANSPOSE_ATTACK_METRIC_FAINT_MARKERS_20261025.md`)에서 별도 과제 두 가지가 남았다.

1. 업시프트 접합이 1–8kHz 배경을 최대 6.4dB 올린다.
2. 접합 뒤 마커 꼬리를 다시 읽는다.

이 문서는 시험 후보 `corr40-split-v3`로 두 가지를 조사한 결과다.

**결론:**

- **"배경 +6.4dB"는 측정 착시였다.** 출력을 원음과 비교해서 생긴 값이다. 음정을 올리면 고조파도 함께 올라가 1kHz 경계에 가까워진다. 원음과 같은 고조파를 이상적으로 음정만 올린 음과 비교하면, 업시프트 출력의 배경은 오히려 0–7dB 낮다.
- **실제 고역 잔여의 주원인은 선형 보간이었다.** 접합 때문이 아니었다.
  - 1–8kHz 성분이 있는 밝은 지속음에서, 고조파 사이 잔여가 이상적 기준보다 중앙값 +10dB, 최대 +34dB 높았다(44.1/48kHz). 다운시프트에서도 생긴다.
  - 출력 읽기만 16탭 윈도 sinc로 바꾼 후보 `corr40-split-v3-sinc`는 중앙값 +0.5dB, 최대 +13dB였다.
- **접합 자체가 남기는 잔여는 작다.** 접합 위치는 정확하다(주기의 정수배, 오차 0.05샘플 이하). v3-sinc에서 남는 최대 +13dB는 접합이 잦은 기타 A1에서만 나오고, 절대값으로는 고조파보다 53dB 이상 낮다.
- **마커 꼬리를 다시 읽는 현상은 실제로 있고, 업시프트에만 있다.** 이벤트 SNR이 10dB 이상인 마커 870개를 봤다.
  - 이벤트 뒤 15–60ms 구간의 고역 peak가 원음보다 중앙값 +5.9dB 높다. 가장 큰 경우는 본 어택보다 6.4dB 낮은 수준이다.
  - 다운시프트는 중앙값 −4.7dB로 생기지 않는다.
  - v3-sinc로도 바뀌지 않는다. 접합 결정이 v3와 같기 때문이다. 별도 과제로 남긴다.
- **v3-sinc의 다른 판정은 v3와 같다.** 기존 시드 T1–T4 판정과 수치, 검출 612/612, 블록 분할 무관(78/78 차이 0)이 v3와 같다. CPU 평균은 13–14% 늘었다.

제품 `Source/`는 바꾸지 않았다. v2·v3 출력은 사전 등록한 렌더러(SHA256 `5625cb…`)와 비트 동일하다. 측정은 합성 입력만 썼다.


> **이름 (2026-10-28):** 이 후보는 측정 때 임시로 `corr40-split-v4`라고 불렀다. 그사이 `main`에 다른 v4가 머지됐다(업시프트 저역 읽기 하한 0.5ms, `TRANSPOSE_V4_LOW_UPSHIFT_20261025.md`). 그래서 이 후보의 이름을 `corr40-split-v3-sinc`로 바꿨다. 근거 폴더 원자료의 엔진 표기 `v4`는 이 후보를 뜻한다. 두 변경은 서로 독립적인 옵션이라 함께 켤 수 있지만, 그 조합은 검증하지 않았다.

## 1. 배경 +6.4dB의 재검토

**입력.** 지난 분석과 같은 마커 없는 지속음이다. 12배음이고 최고 고조파는 370–660Hz다. 3 표본률 × 3 악기 × 4 반음으로 쟀다.

**지표.** 1–8kHz 2ms RMS의 최댓값이다(시작 0.5초, 끝 0.3초 제외).

| 반음 | 출력 / 원음 (지난 분석의 비교) | 출력 / 이상적으로 올린 음 |
|---|---|---|
| −2 | −6.7 ~ −5.4dB | −0.2 ~ +1.1dB |
| −1 | −3.2 ~ −2.7dB | 0.0 ~ +0.6dB |
| +1 | −2.1 ~ +2.3dB | −5.3 ~ −0.9dB |
| +2 | −1.0 ~ **+6.4dB** | −7.2 ~ 0.0dB |

이 입력의 1–8kHz '배경'은 최고 고조파가 대역 필터 경계로 새어 든 성분이다. 그래서 음정을 올리면 늘고, 내리면 준다. 접합 지점 근처(접합 전 1ms ~ 후 5ms)를 그 밖과 따로 비교해도 접합 근처가 더 높지 않았다(48kHz).

**지난 문서 정정.** 지난 문서는 "업시프트 접합이 배경을 올린다"고 적었다. 이를 "음정 이동에 따른 정상 변화"로 정정한다. 약한 마커의 어택 지표가 불안정했다는 결론은 그대로다. 그 마커가 배경과 구별되지 않는다는 점이 원인이기 때문이다.

## 2. 고역 잔여의 원인

**입력.** 1–8kHz에 실제 성분이 있는 밝은 지속음이다. 고조파는 8kHz까지 있고, 진폭은 1/h와 1/√h 두 가지로 만들었다.

**지표.** 1–8kHz 안에서 고조파 사이(고조파에서 ±f/4 밖)의 에너지를 고조파 에너지와 비교한 값이다(Welch, 32768점). 같은 고조파를 이상적으로 올린 음에서도 같은 값을 재서, 그보다 얼마나 높은지를 '초과량'으로 적었다.

**변형 실험** (48kHz, 1/√h). 실험용 사본에 조절 손잡이를 붙여 비교했다(`experiment-knobs.patch`).

| 변형 | 초과량 |
|---|---|
| v3 (선형 보간) | +4.0 ~ +26.6dB |
| 출력 읽기만 4점 Hermite | +0.2 ~ +18.7dB |
| 출력 읽기만 16탭 sinc | +0.0 ~ +13.4dB |
| 고역 경로 접합 페이드 4ms → 8ms | 개선 없음. A0 ±2에서는 잔여가 고조파 대비 −13dB까지 커짐 |
| 고역 경로 접합 탐색을 800Hz 저역 대신 고역 신호 전체로 | 개선 없음. A0 +2에서는 잔여가 고조파 대비 −19dB까지 커짐 |

출력 읽기만 바꾼 변형은 접합·onset 결정이 v3와 완전히 같다(출력 비트만 다름).

**접합 위치.** 기타 A1 +2반음(48kHz)에서 접합마다 점프 길이를 기록했다.

- 고역 경로는 매번 1주기를 뛰었다(21회. 첫 접합 1.001 주기, 나머지 872.7샘플 = 1.000 주기).
- 저역 경로는 2주기를 뛰었다.

접합 위치 오차는 0.05샘플 이하다. 다만 1주기씩 뛰므로 고역 경로의 접합이 저역 경로의 두 배다. 남는 미세한 위치 오차가 8kHz에서 위상 차이(약 0.05rad)가 되고, 4ms 크로스페이드 동안 진폭 요동을 만든다. sinc 뒤에 남는 기타 A1 잔여는 이것으로 설명된다.

## 3. 후보 v3-sinc: 출력 읽기만 윈도 sinc

**구현.** `CorrelationPitch::setSincOutput`, `TransientSplitPitch::setSincOutput`. 기본값은 꺼져 있다.

- 16탭 Kaiser(β 8) 윈도 sinc를 쓴다. 4096 위상 표에서 가장 가까운 위상을 고른다.
- 접합 탐색은 기존 선형 읽기를 그대로 쓴다. 그래서 접합·onset 결정이 v3와 같다.
- 커널이 대칭이라 지연이 늘지 않는다. 8샘플 더 최근 샘플이 필요하지만, 읽기 지연은 최소 2ms 아래로 내려가지 않는다.

`TransposeProbe`·`SpliceTrace`·`BlockInvariance`에 엔진 이름 `corr40-split-v3-sinc`(`v3-sinc`)를 추가했다.

| 표본률 | v3 초과량 (중앙값 / 최대) | v3-sinc 초과량 (중앙값 / 최대) | 고조파 손실 v3 → v3-sinc |
|---|---|---|---|
| 44.1kHz | +9.9 / +34.0dB | +0.6 / +13.4dB | −0.50 → −0.26dB |
| 48kHz | +10.2 / +26.6dB | +0.5 / +13.4dB | −0.46 → −0.26dB |
| 96kHz | 0.0 / +4.2dB | 0.0 / +0.1dB | −0.32 → −0.26dB |

96kHz에서는 선형 보간도 거의 문제가 없다. 신호가 표본률에 비해 충분히 낮은 주파수이기 때문이다. v3-sinc에서 남는 +5dB 이상은 모두 기타 A1이다(위 2의 접합 위상).

**기존 시드 목표 평가** (`latency_targets.py`, 목표 정의 버전 2, 612 렌더).

| 목표 | v3 | v3-sinc |
|---|---|---|
| T1 어택 (SNR ≥ 10dB) | PASS 5.583ms (5,324 이벤트) | PASS 5.583ms |
| T1 약한 이벤트 | 412개, 최대 5.146ms | 같음 |
| T2 다운시프트 저역 | 짧은 음 6.377 / 긴 음 9.338ms | 같음 |
| T3 업시프트 저역 | 10.542 / 14.425 / 17.859 / 10.008ms | 짧은 음 10.541, 나머지 같음 |
| T4 품질 | 워블 0.593 cents, 오검출·누락·저역 재설정 0 | 같음 |

- **검출:** 612/612 렌더에서 onset 재설정, 짝 맞춤, 저역 재설정이 같다.
- **저역 지연 차이:** 최대 0.004ms.
- **어택 지연 차이** (판정에 쓰는 이벤트 5,324개):
  - 1샘플보다 큰 차이는 347개다. 2ms RMS peak 위치가 고역 성분 변화로 조금 움직인 것이다.
  - 가장 큰 차이는 1.27ms다. SNR 11.8dB인 마커 0.001 하나에서 나왔다.
  - 판정에서 빠지는 무작위 마커 입력에서는 최대 51ms까지 바뀐다. 배경 수준의 마커라 peak가 아무 데나 잡히는 기존 현상이다.

**블록 분할.** 3 입력 × 2 반음에 대해 블록 크기를 13가지로 바꿔 봤다(1–4096 고정, 무작위 512·4096). 모두 차이 0이었다.

**CPU** (48kHz, 12초 리프, −2반음, 콜백당 스레드 CPU, 공유 VM, 번갈아 5회, 중앙값).

| 블록 | 평균 v3 → v3-sinc | p99 | 최대 |
|---|---|---|---|
| 64 | 58.4 → 66.5µs (+14%) | 151 → 187µs | 364 → 358µs |
| 128 | 118.2 → 133.1µs (+13%) | 268 → 330µs | 409 → 613µs |

- 최대값은 공유 VM이라 흔들림이 크다.
- 64샘플 블록 예산(1,333µs)에 비하면 평균 증가는 0.6%p다.
- T5 판정은 이전처럼 전용 하드웨어에서 해야 한다.

## 4. 마커 꼬리 다시 읽기

**대상.** 기존 시드의 마커 입력 세 종류다.

- 지속음 위 마커 0.004
- 지속음 위 마커 0.001
- 무작위 마커 8139/20261024

이 중 이벤트 SNR ≥ 10dB인 870개 이벤트를 3 표본률 × 4 반음으로 쟀다.

**지표.** 이벤트 뒤 0–15ms의 1–8kHz peak 대비, 15–60ms 구간 peak의 비율이다(다음 이벤트 5ms 전까지). 출력값과 원음값의 차이를 본다.

| | 원음 비율 (중앙값) | 출력 비율 (중앙값 / 최대) | 출력 − 원음 (중앙값) | 6dB 넘게 늘어난 이벤트 |
|---|---|---|---|---|
| 다운시프트 (v3) | −37.4dB | −40.8 / −13.2dB | −4.7dB | 127 / 870 |
| 업시프트 (v3) | −37.4dB | −30.7 / **−6.4dB** | **+5.9dB** | **431 / 870** |
| 업시프트 (v3-sinc) | −37.4dB | −30.9 / −6.5dB | +5.9dB | 431 / 870 |

- **해석:**
  - 업시프트는 onset 재정렬 뒤 고역 경로가 4ms 재정렬 보호 구간만 지나면 1주기를 거꾸로 뛴다.
  - 그래서 어택 바로 뒤 꼬리를 한 번 더 읽는 구조다.
  - 이 과정이 마커 직후 15–60ms에 고역 에너지를 더한다. 가장 큰 경우는 본 어택보다 6.4dB 낮은 크기다.
- **v3-sinc와의 관계:** 이 문제는 보간과 무관하다. v3-sinc의 다운시프트에서 6dB 초과 수가 늘어난 것(127 → 187)은 v3-sinc가 꼬리의 고역을 덜 깎기 때문이다. 출력 비율의 최대값과 중앙값은 그대로다.
- **남은 일:** 보호 구간을 늘리거나 꼬리 구간을 건너뛰는 점프를 시험하는 것. 다만 보호 구간 4ms는 v2에서 T1 실패를 고치려고 정한 값이다. 바꾸려면 T1–T4 전체를 다시 검증해야 한다.
- **실제 청취:** 들리는지는 T6 청취 시험에서 확인한다. 청취 항목에 업시프트 지속음 위 약한 피킹을 넣는 것을 제안한다.

## 5. 정리와 다음 단계

1. **v3-sinc의 지위:** 고역 잔여를 줄인 연구 후보다. 기존 시드 판정은 v3와 같다. v3를 대체하려면 다음 두 가지가 필요하다.
   - 사전 등록한 새 시드 검증. 판정 수치가 v3와 같을 것으로 보지만, 등록 없이는 쓰지 않는다.
     - 2026-10-29 실시(`TRANSPOSE_V3SINC_FRESH_SEED_20261029.md`): 지연·검출·고정 PDC·블록 분할은 통과했다. 고역 잔여 기준은 기준 설정 오류로 실패했다(넓힌 기본음 범위에 좁은 범위 기준을 적용함).
   - T6 청취
2. **업시프트 앨리어싱:** 이번 입력은 8kHz까지만 성분이 있었다. 실제 DI의 고역(10kHz 이상)은 업시프트 때 나이퀴스트를 넘어 접힐 수 있다. 선형 보간과 v3-sinc 모두 이를 막지 않는다. 실제 DI 검증에서 확인할 항목으로 남긴다.
3. **마커 꼬리 다시 읽기:** 위 4의 별도 과제다.
4. **연구용 플러그인:** v3-sinc는 아직 넣지 않았다. 청취 시험에 쓰려면 엔진 선택지에 추가해야 한다.
