# 호스트 검증 체크리스트 — EQ 표시 범위와 커서 수치 표시 (2026-11-05 KST)

PR #261(Issue #53)에서 추가한 그래픽 EQ의 **표시 범위(±6 / ±12 / ±24 dB)**와 **커서 수치 표시** 가운데, CI의 자동 테스트로는 확인할 수 없는 것을 실제 DAW에서 확인하기 위한 목록입니다.

- **CI가 이미 확인한 것:** `ChimeraGraphicalEQUITests`의 `displayRangeAndReadout`과 `liveAnalyzer`. 범위별 노드 위치, 지원하지 않는 값 거부, 범위 전환 후 저장 상태·모든 호스트 파라미터·Undo/Redo·A/B 슬롯 불변, 화면 밖 노드의 가장자리 표시와 실제 값 기준 드래그, A/B·공장 프리셋 뒤 범위 유지, 실제 오디오로 IN/OUT/LIVE/Freeze 조합별 수치 문자열. 이 목록은 이를 반복하지 않고, 3번 항목만 짧게 다시 봅니다.
- **CI가 확인하지 못한 것:** 오른쪽 클릭 메뉴 자체(비동기 팝업), 메뉴가 열린 채 에디터를 닫는 경우, 실제 DAW 창에서의 표시, 호스트 자신의 Undo·프로젝트 저장·오토메이션과의 관계.
- **판정:** 항목마다 **PASS / FAIL / 보류**를 적고, FAIL이면 재현 방법을 함께 적습니다.
- **근거:** [EQ_EDITING_OCT23.md](EQ_EDITING_OCT23.md)의 "표시 범위와 커서 수치 표시".
- **함께 쓰는 체크리스트:** 전체 호스트 검증은 [HOST_VERIFICATION_CHECKLIST_20261101.ko.md](HOST_VERIFICATION_CHECKLIST_20261101.ko.md)를 따릅니다.

## 0. 준비

- [ ] **빌드 기록:** 테스트한 커밋 SHA(main `2482fdf` 이후), OS와 버전, 호스트와 버전, 포맷(VST3 / AU / AAX / Standalone), 샘플레이트, 버퍼 크기, 화면 배율(100% / 150% / 200%, Retina 여부).
- [ ] **시험 신호:** 1 kHz 사인, 약 −20 dBFS를 트랙에 재생합니다.
- [ ] **EQ 설정:** Tone EQ의 Band 1을 Peak, 1 kHz, +6 dB로 켭니다. 분석기는 LIVE, IN, OUT 모두 켭니다.

## 1. 오른쪽 클릭 표시 범위 메뉴

- [ ] **메뉴 열기:** 그래프의 빈 곳을 오른쪽 클릭하면 "EQ display range" 제목과 `+/-6 dB`, `+/-12 dB`, `+/-24 dB` 항목이 뜹니다.
- [ ] **현재 범위 표시:** 현재 범위에 체크 표시가 있습니다. 에디터를 처음 열면 `+/-24 dB`입니다.
- [ ] **전환:** 각 항목을 고르면 바로 다시 그려집니다.
  - 기준: 가로 격자와 숫자 간격은 아래와 같습니다. 0 dB 선은 밝게 그려집니다.

    | 범위 | 격자 간격 | 숫자 |
    |---|---|---|
    | ±24 dB | 6 dB | −24, −12, 0, +12, +24 |
    | ±12 dB | 3 dB | −12, −6, 0, +6, +12 |
    | ±6 dB | 1 dB | −6, −3, 0, +3, +6 |
- [ ] **노드 위 오른쪽 클릭:** 밴드 노드 위에서는 범위 메뉴가 아니라 `Delete Band N` 메뉴가 뜹니다. 좁은 범위에서 가장자리에 붙은 노드도 마찬가지입니다.
- [ ] **macOS 입력:** Ctrl+클릭, 트랙패드 두 손가락 클릭에서도 같은 메뉴가 뜹니다.
- [ ] **취소:** 메뉴를 연 채 Esc를 누르거나 바깥을 클릭하면 아무것도 바뀌지 않습니다.
- [ ] **메뉴가 열린 채 에디터 닫기 (중요):** 메뉴를 연 상태에서 아래 방법으로 에디터를 닫습니다. 방법마다 따로 확인합니다.
  - 호스트의 플러그인 창 닫기 버튼, 창 닫기 단축키, 트랙 삭제, 플러그인 제거
  - 기준: 크래시나 멈춤이 없고, 다시 열면 정상이며 범위는 `+/-24 dB`입니다.
- [ ] **메뉴가 열린 채 다른 조작:** 메뉴를 연 채 Tone EQ ↔ Final EQ를 전환하거나 창 크기를 바꿉니다.
  - 기준: 크래시가 없고, 선택한 범위는 메뉴를 연 패널에만 적용됩니다.
- [ ] **메뉴 위치:** 화면 가장자리, 다중 모니터, 배율이 다른 모니터에서 메뉴가 잘리지 않고 플러그인 창이 있는 모니터에 뜹니다.

## 2. 커서 수치 표시

- [ ] **표시와 사라짐:** 그래프 위에 마우스를 올리면 그래프 오른쪽 위 상자에 `주파수   ±dB`가 뜹니다. 그래프 밖으로 나가면 사라집니다.
- [ ] **형식:** 1 kHz 이상은 `1.00 kHz`처럼 소수 둘째 자리, 100 Hz~1 kHz는 정수 Hz, 100 Hz 미만은 소수 첫째 자리 Hz입니다. dB는 `+6.0 dB`처럼 부호와 소수 첫째 자리입니다.
- [ ] **드래그 중 갱신:** 노드를 드래그하는 동안에도 값이 갱신됩니다.
- [ ] **가림·잘림:** 상자가 툴바, 노드, 눈금 숫자를 가리거나 그래프 밖으로 잘리지 않습니다. 전체 작업 공간과 컴팩트 작업 공간 모두 확인합니다.
- [ ] **화면 배율:** 100% / 150% / 200%(Windows), Retina와 일반 모니터(macOS)에서 글자가 흐리거나 상자 밖으로 넘치지 않습니다.
- [ ] **상태별 레벨 표시:** 재생 중 커서를 1 kHz에 두고 아래 조합을 확인합니다.

  | LIVE | IN | OUT | Freeze | 기준 |
  |---|---|---|---|---|
  | 켬 | 켬 | 켬 | 끔 | `OUT … dBFS` |
  | 켬 | 켬 | 끔 | 끔 | `IN … dBFS`, OUT일 때보다 약 6 dB 낮음 |
  | 켬 | 끔 | 켬 | 끔 | `OUT … dBFS` |
  | 켬 | 끔 | 끔 | 끔 | **레벨 없음** (주파수와 dB만) |
  | 끔 | 아무거나 | 아무거나 | 끔 | 레벨 없음, 그래프에 "Analyzer off" |
  | – | 켬 | 켬 | 켬 | `OUT … dBFS`, 재생을 멈춰도 숫자가 바뀌지 않음 |
  | – | 켬 | 끔 | 켬 | `IN … dBFS`, 고정된 값 |
  | – | 끔 | 끔 | 켬 | **레벨 없음** |

- [ ] **Freeze 유지:** Freeze 중 Tone EQ ↔ Final EQ를 오갔다 돌아와도 같은 위치의 숫자가 그대로입니다.
- [ ] **재생 정지:** LIVE를 켠 채 재생을 멈추면 레벨이 그래프의 스펙트럼과 같은 방식으로 줄어들거나 멈추고, "Waiting for fresh audio" 같은 안내와 모순되지 않습니다.
- [ ] **나이퀴스트 위:** 44.1 kHz 세션에서 커서를 22 kHz 근처에 두면 레벨이 나오지 않습니다.

## 3. 좁은 범위에서의 편집 (CI 확인 항목, 짧게 확인)

- [ ] **가장자리 노드:** Band 1을 +18 dB로 두고 `+/-6 dB`를 고르면 노드가 그래프 위 가장자리에 붙어 보이고 클릭으로 선택됩니다.
- [ ] **실제 값 기준 드래그:** 그 노드를 Alt를 누른 채 옆으로 드래그하면 게인은 +18 dB 그대로이고 주파수만 바뀝니다. +6 dB로 튀지 않습니다.
- [ ] **세밀한 조정:** 좁은 범위에서는 같은 마우스 이동이 더 작은 dB 변화가 됩니다. Shift 미세 조정도 정상입니다.
- [ ] **밴드 추가:** 빈 곳을 더블클릭하면 커서 위치의 주파수와, 현재 범위 기준 dB로 밴드가 생깁니다.

## 4. 호스트 상태와의 분리

표시 범위는 Freeze·PEAK와 같은 **화면 상태**입니다. 파라미터, 프리셋, A/B, Undo, 저장 상태에 들어가지 않습니다.

- [ ] **프로젝트 수정 표시:** 범위만 바꾸면 호스트 프로젝트가 "수정됨"으로 바뀌지 않습니다. (호스트마다 기준이 달라 바뀐다면 어떤 호스트인지 기록)
- [ ] **호스트 Undo 목록:** 범위 변경이 호스트 Undo 목록에 기록되지 않습니다. 플러그인의 Undo/Redo 버튼 상태도 그대로입니다.
- [ ] **호스트 Undo 후 범위:** EQ를 한 번 편집하고 범위를 바꾼 뒤 호스트 Undo를 하면, EQ 편집만 되돌아가고 범위는 그대로입니다.
- [ ] **오토메이션 기록:** 오토메이션을 기록하는 동안 범위를 바꿔도 오토메이션 레인에 아무것도 기록되지 않습니다.
- [ ] **오토메이션 재생:** 게인 오토메이션 재생 중에 범위를 바꾸면 소리와 파라미터 값은 변하지 않고, 노드가 오토메이션을 정확히 따라갑니다.
- [ ] **A/B·프리셋:** A/B 전환, 공장 프리셋 로드, 호스트 프리셋 저장/불러오기를 하면 EQ 값은 바뀌어도 범위는 그대로입니다.
- [ ] **저장·다시 열기:** 범위를 `+/-6 dB`로 두고 프로젝트를 저장, 닫기, 다시 엽니다.
  - 기준: EQ 값은 복원되고, 범위는 `+/-24 dB`로 시작합니다.
- [ ] **인스턴스 독립:** 같은 세션의 플러그인 인스턴스 두 개는 범위가 서로 독립입니다. 한 인스턴스 안의 Tone EQ와 Final EQ도 서로 독립입니다.
- [ ] **소리 불변:** 범위를 바꾸기 전과 후에 같은 구간을 오프라인 바운스해 위상을 뒤집어 합치면 완전히 상쇄됩니다.

## 5. 권장 호스트 조합

모든 조합을 할 필요는 없습니다. OS마다 최소 하나씩, 그리고 AAX를 배포한다면 Pro Tools를 포함합니다.

- [ ] **Windows:** Cubase 또는 Reaper(VST3), Pro Tools(AAX, 서명된 빌드)
- [ ] **macOS:** Logic Pro(AU), Ableton Live(VST3 또는 AU), Pro Tools(AAX)
- [ ] **Linux:** Reaper 또는 Bitwig(VST3)
- [ ] **모든 OS:** Standalone
