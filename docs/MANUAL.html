공개 베타의 앰프·이펙터는 레퍼런스에서 영감을 얻은 독립 알고리즘입니다. 실제 기기의 회로 복제나 측정 일치를 보증하지 않습니다. 화면에 함께 나오는 제조사·제품명은 소리의 설계 방향을 설명하는 참고 명칭이며 제휴·인증을 뜻하지 않습니다.

01 · 설치와 첫 소리

  1. 실행 중인 Chimera와 DAW를 종료한 뒤 운영체제용 설치 파일을 실행합니다. 설치 경로와 서명 상태는 동봉된 INSTALLATION.md를 확인하세요.
  2. 단독 실행에서는 Options / Audio settings에서 오디오 인터페이스와 입출력 채널을 선택합니다. DAW에서는 오디오 트랙에 VST3를 삽입하고 입력 모니터링을 켭니다. macOS에서는 AU도 사용할 수 있습니다.
  3. 악기를 인터페이스의 악기용 입력에 연결하고 MONO L을 선택합니다. 실제 스테레오 소스를 받을 때만 STEREO를 사용합니다. 헤드폰·스피커 출력 레벨을 먼저 낮춥니다.
  4. INPUT 미터가 움직이는지 확인하고 과도한 입력 피크가 생기지 않도록 인터페이스 게인을 조정합니다. 처음에는 Classic과 클린 계열 프리셋으로 확인합니다.
  5. 4x oversampling이 기본입니다. 끊김이 있으면 2x/1x로 낮추거나 인터페이스 버퍼를 늘립니다. 샘플레이트는 DAW/드라이버에서 설정합니다.
  6. 현재 상태를 SAVE AS로 저장하고 DAW 프로젝트도 저장합니다. 사용자 IR은 상태에 포함되므로 원본 파일을 옮겨도 저장된 소리를 다시 열 수 있습니다.

Windows는 ASIO를 지원하는 인터페이스 드라이버를 선택하면 실시간 연주 설정이 수월합니다. ASIO가 목록에 없다면 현재 바이너리의 지원 여부와 드라이버 설치를 확인하고 Windows Audio를 사용할 수 있습니다. 입력이 없는 장치나 출력 채널이 잘못 선택된 경우 플러그인 설정만으로 소리가 나지 않습니다.

02 · 신호 흐름과 세 가지 모드

INPUT → Gate → Transpose → PRE → Rigs / Cabinets → Merge → POST → Doubler / OUTPUT

튜너는 Gate와 Transpose 전의 원음을 읽습니다. A/B는 두 개의 전체 사운드 스냅샷으로, 좌우 채널이나 Dual의 두 앰프를 선택하는 버튼이 아닙니다.

모드동작사용 예
Classic한 개의 전체 대역 앰프·캐비닛 경로. 일반적인 앰프 EQ를 사용합니다.클린, 크런치, 리듬 기타, 기본 베이스 톤
Dual · Blend두 개의 전체 대역 리그를 BLEND로 섞습니다. 기타+기타, 기타+베이스, 베이스+베이스 모두 가능하며 악기 입력을 자동으로 분리하는 기능은 아닙니다.타이트한 앰프와 두꺼운 앰프 혼합
Dual · CrossoverLR4 크로스오버로 낮은 대역과 높은 대역을 나누어 각각 처리합니다. 크로스오버 값과 대역별 Band Tone을 확인합니다.깨끗한 저음 + 드라이브 중고음
MatrixLOW / MID / HIGH 세 대역. LOW는 COMP, LEVEL, BAND TONE, DI/AMP 블렌드를 사용합니다. MID/HIGH에는 각 DRIVE·LEVEL·BAND TONE이 있습니다.다운튜닝, 확장 음역, 저음 보존, 복합 디스토션

Matrix LOW는 Fuzz/Boost/Overdrive 앞의 깨끗한 신호를 받습니다. LOW 헤드의 drive는 0으로 고정되며, DI/AMP로 선택한 앰프·캐비닛의 비율을 정합니다. 낮은 대역의 헤드 drive를 감추더라도 Classic/Dual의 저장된 drive 값은 유지합니다. 대역 분할은 소리의 기본음·배음에 적용되며, 악기별로 다른 입력을 라우팅하는 기능이 아닙니다.

위쪽 / 아래쪽 공통 기능

INPUT / OUTPUT입출력 게인과 레벨 미터. OUTPUT은 최종 레벨을 맞추는 용도로 사용합니다.
GateTHRESH는 작동 기준, HOLD는 닫히기 전 유지 시간, RELEASE는 닫히는 속도입니다. 소리 끝이 잘리면 THRESH를 낮추거나 HOLD/RELEASE를 늘립니다.
Transpose−12~+12 반음. 활성 상태에서 표시된 지연이 추가되며 DAW에 전달됩니다. 코드와 짧은 어택은 설정에 따라 아티팩트가 날 수 있습니다.
Doubler스테레오 폭을 만드는 짧은 지연. 모노 합산 시 음색이 달라질 수 있으므로 모노 출력도 확인합니다.
Tuner / AUTO MUTE크로매틱 튜너, A4 기준 조절. AUTO MUTE가 켜져 있으면 튜닝 중 출력이 무음입니다.
MIDI / TAP / HOST / CLICKMIDI CC 학습, 수동/탭 BPM, 호스트 템포, 연습용 클릭. 딜레이 SYNC는 4분음표를 따라갑니다.
CPU / SIZE평균·피크 CPU는 오디오 콜백 시간 예산을 기준으로 합니다. SIZE 또는 창 크기로 화면을 조절합니다.

03 · PRE 페달과 게인 순서

Compressor, Envelope, Fuzz, Boost, Overdrive 각 계열에 여러 모델이 있습니다. 모델 아래의 원본 기기명은 레퍼런스입니다. 계열 ON/OFF와 노브 값은 별개로 저장됩니다.

TOUCH는 Envelope → Compressor로 피킹 반응을 우선합니다. SUSTAIN은 Compressor → Envelope로 입력 레벨을 정리한 뒤 필터를 움직입니다. 컴프레서가 앞에 있으면 필터의 반응 폭이 줄어들 수 있으므로 감도와 threshold를 다시 조절하세요.

Fuzz → Boost → Overdrive는 퍼즈를 앞에 두고 부스트로 다음 드라이브단의 포화를 조절하는 실용적인 기본 순서입니다. Boost가 Overdrive 앞에 있으면 음량 상승보다 게인·압축 증가가 먼저 나타날 수 있습니다. 전체 음량만 올리고 싶으면 리그 LEVEL 또는 OUTPUT을 사용하세요. 실제 Fuzz Face의 입력 임피던스와 기타 볼륨 상호작용까지 동일하게 재현하는 의미는 아닙니다.

Fuzz → Overdrive → Boost 옵션은 드라이브 뒤로 부스트를 옮깁니다. 뒤의 앰프에 헤드룸이 있을 때 레벨을 더 올릴 수 있지만 앰프까지 포화되면 게인도 증가하므로 깨끗한 솔로 부스트를 보장하지 않습니다. 게인 순서를 바꾼 뒤에는 피크 레벨을 맞춰 비교합니다. 퍼즈·드라이브의 작은 값 차이도 다음 단의 동작을 바꾸므로, 여러 게인 페달을 동시에 강하게 올리는 것부터 시작하지 않는 편이 조정하기 쉽습니다.

04 · 앰프와 캐비닛 / IR

총 15개 앰프 선택 메뉴에서 자체 모델명과 레퍼런스 기기명을 함께 확인합니다. 추가된 Chime 30 / Orange Crown / Bassman Valve / Subway Clean은 각각 VOX AC30 Top Boost / Orange Rockerverb 50 MKIII / Fender Super Bassman / Mesa Subway D-800+를 참고한 독립 알고리즘입니다. Match Chime / Silk ODS / Taste Punch는 각각 Matchless DC-30 / Dumble Overdrive Special / EICH T900을 참고합니다. Matchless/Dumble의 클론 캡처는 실제 원본 기기 캡처와 구분하며, EICH T900의 정확한 NAM 레퍼런스는 확보되지 않았습니다. 참고 캡처가 있다는 것만으로 기기 재현 일치도를 보증하지 않습니다. 같은 preset이라도 IR을 바꾸면 고역, 저음 공진, 상대 음량이 크게 달라질 수 있습니다. 먼저 헤드/캐비닛을 정하고 DRIVE와 EQ를 맞추세요.

  • CAB: 내장 factory IR 또는 실제 설치된 사용자 IR을 선택합니다. BYPASS는 캐비닛 처리만 우회합니다. 실제 기타 캐비닛으로 출력할 때 사용할 수 있습니다.
  • LOAD / 파일 드롭: WAV/AIFF, 모노·스테레오, 최대 1초·4 MB 범위의 IR을 리그에 불러옵니다. 길거나 큰 파일은 먼저 오디오 편집기에서 확인합니다.
  • IR LIBRARY: 악기/크기/마이크 등으로 목록을 필터링합니다. 표시 이름은 간단하게 정리되고 상세 정보에서 원본 파일명·출처를 확인할 수 있습니다.
  • Available / Missing: 실제 파일이 있는 항목만 로드할 수 있습니다. 출처 목록이 있다는 사실만으로 그 IR 음원이 설치된 것은 아닙니다.
  • ADD FOLDER / 개인 ZIP: 사용 권한을 가진 IR 폴더 또는 기존 개인 팩을 추가합니다. 공개 설치 파일은 개인 팩의 제한된 IR을 포함하지 않습니다.
  • LOW CUT / HIGH CUT: 불필요한 저음·고음을 정리합니다. 지나치게 좁히면 소리가 사라지므로 밴드 모드에서는 대역과 함께 확인합니다.
  • MUTE / SOLO / POLARITY: 경로별 비교와 합산 점검용입니다. 리그가 들리지 않으면 mute/solo 상태부터 확인합니다.

Factory IR의 크레딧·배포 조건은 THIRD_PARTY_NOTICES.md에 있습니다. 사용자 IR이 포함된 프리셋·프로젝트를 다른 사람에게 보낼 때는 해당 IR의 공유 조건을 확인하세요.

05 · POST 랙

POST는 리그 합산 후 Bus Compressor → Preamp → EQ → Modulation → Delay → Reverb 순서입니다. 화면의 랙 전면 이미지는 각 슬롯의 실제 표시 비율에 맞춘 디자인이며 노브와 스위치는 별도로 동작합니다.

Bus CompThreshold, Ratio, Attack, Release, Makeup. GR 표시로 압축량을 확인합니다. Makeup을 올려 단순히 더 큰 소리와 비교하지 않도록 합니다.
PreampGain은 채색·포화에, Colour는 성향에, Trim은 다음 단으로 보내는 레벨에 영향을 줍니다.
EQ저역·고역 쉘프와 주파수/게인/Q를 조정하는 중역. 모델에 따라 쉘프 위치와 곡선이 다릅니다.
ModulationRate, Depth, Mix. 코러스·디멘션·페이저·플랜저·비브라토·트레몰로 계열.
DelayTime, Feedback, Mix. SYNC 활성 시 템포를 따릅니다. 높은 Feedback은 반복음을 길게 유지하므로 최종 레벨을 확인합니다.
ReverbSize, Damping, Mix. Plate/Hall/Spring 계열. 저역이 번지면 Mix와 Size부터 낮춥니다.

06 · 추천 프리셋과 저장

31개 추천 프리셋은 Guitar Clean/Edge/Rock/High Gain/Lead, Bass Clean/Pick/Slap/Drive/Fuzz/Envelope, Dual Guitar+Guitar/Guitar+Bass/Bass+Bass, Matrix Bass/Experimental, Texture Envelope/Fuzz로 세분화됩니다. 악기, 라우팅, 연주 용도를 기준으로 골라 시작합니다. 사용자의 픽업 출력·튜닝·연주 강도에 맞춘 최종 레벨까지 보장하는 값은 아닙니다. 베이스에서는 저음 보존과 중고음 드라이브 비율을 먼저, 기타에서는 리듬/리드의 중역과 공간계 양을 먼저 조정하세요.

  1. 목적에 가까운 추천 프리셋을 선택합니다.
  2. INPUT과 Gate를 악기에 맞춘 뒤 IR을 선택합니다.
  3. DRIVE, 리그 LEVEL과 블렌드/대역을 조절합니다.
  4. A/B의 COPY로 기준 상태를 복사하고 두 소리를 비슷한 음량으로 비교합니다.
  5. SAVE AS로 개인 사운드를 저장합니다. OPEN으로 다시 불러올 수 있습니다.

신규 Matchless Edge, Dumble Smooth Lead, EICH Modern Clean은 추가 헤드의 용도를 바로 확인할 수 있는 시작점입니다. 추천 프리셋은 이전 사운드의 이펙트 켜짐 상태까지 초기화한 뒤 정의된 음색을 적용합니다. 입력 게인·입력 채널, 템포·클릭·튜너·MIDI 같은 연주 환경 설정은 유지합니다. 프로젝트는 파라미터와 IR을 보관합니다. 이전 개발 버전의 정규화된 모델 선택 자동화는 모델 수 확장에 따라 재검토가 필요할 수 있습니다. 중요한 세션은 복사본으로 열고 모델명·값·IR을 확인한 뒤 저장하세요.

07 · 매뉴얼, 버그 리포트, 업데이트

앱의 SETTINGS → Manual / Bug report / Updates에서 이 오프라인 매뉴얼, 버그 리포트, 업데이트 확인 기능에 접근합니다. 이 문서는 인터넷 연결 없이 열 수 있습니다.

버그 리포트

발생 단계, 기대한 결과, 실제 결과, 운영체제, DAW와 버전, 샘플레이트/버퍼, 사용 모델과 라우팅을 적습니다. 앱이 준비하는 진단 내용을 확인하고 공유할 정보를 선택한 뒤 보고서를 제출하세요. 화면·오디오·프리셋은 문제 재현에 도움이 되지만 개인 IR을 공개 첨부하지 않도록 확인합니다. 오류 보고 기능이 사용자 대신 임의로 메시지를 보내지는 않습니다.

업데이트

베타 채널의 새 버전을 확인하고 운영체제에 맞는 설치 파일을 받을 수 있습니다. 다운로드의 크기와 SHA256이 릴리즈 명세와 일치하는지 검증합니다. SHA256 일치는 다운로드 무결성 확인이며 퍼블리셔 코드서명을 대신하지 않습니다. 다운로드 후 작업을 저장하고 DAW/Chimera를 종료한 다음 설치하세요. 플러그인이 실행 중인 오디오 처리 과정에서 바이너리를 교체하지 않습니다.

공식 릴리즈에 아직 게시되지 않은 버전은 업데이트 서버에서 발견되지 않을 수 있습니다. 네트워크 오류가 생겨도 현재 오디오 세션은 계속 사용할 수 있습니다. 공개 전 준비 단계의 설치 파일은 자동 업데이트 서버 등록을 뜻하지 않습니다.

English · Quick reference

Install and first sound

Close Chimera and the DAW before installation or update. Install the package for your operating system; see INSTALLATION.md. In the standalone audio settings choose your interface and input/output channels. In a DAW, insert the VST3 or macOS AU on an audio track and enable input monitoring. Choose MONO L for a single instrument input, or STEREO for a real stereo source. Start with a low physical monitoring level, a clean Classic preset, and verify the input meter.

The standard oversampling setting is 4x. Lower it to 2x/1x or raise the device buffer if audio breaks up. Sample rate and buffer configuration belong to the host/driver. Save a reference with SAVE AS and save your DAW session. User IR audio is embedded in saved state so moving its original file does not invalidate recall.

Routing

Input / Gate / Transpose → PRE → Amp & Cabinet rigs → Merge → POST → Doubler / Output

ClassicOne full-range amp/cabinet rig with conventional EQ.
Dual BlendTwo full-range rigs and adjustable blend; guitar+guitar, guitar+bass or bass+bass voicings process the input signal, not separate detected instruments.
Dual CrossoverLR4 low/high split and band tone controls.
MatrixLOW compression, level, band tone and DI/AMP blend; separate MID/HIGH drive, level and band tone. LOW receives the tap before Fuzz/Boost/Overdrive. LOW amp drive is fixed at zero; stored Classic/Dual drive values are preserved.

PRE / POST

TOUCH places Envelope before Compressor for playing dynamics. SUSTAIN places Compressor first for steadier input. The default gain order Fuzz → Boost → Overdrive lets fuzz retain an early position while boost controls the following drive. A boost before a clipping stage may add saturation rather than output level; use rig LEVEL or OUTPUT for final loudness. The alternate Fuzz → Overdrive → Boost order moves boost after drive. It can lift level if the downstream amp has headroom; it does not guarantee a clean solo lift. The algorithms do not claim physical pickup-impedance interaction.

POST processes the combined rigs: Bus Compressor → Preamp → EQ → Modulation → Delay → Reverb. Match output levels when comparing dynamics and saturation. Delay SYNC follows quarter-note tempo; HOST follows DAW tempo. The chromatic tuner reads the original input before gate/transpose; AUTO MUTE silences output while tuning. MIDI CC Learn, TAP/manual BPM and CLICK support performance and practice. A/B contains complete sounds, not left/right channels. Doubler may change timbre when summed to mono.

Amps / cabinets

Fifteen amp voices show short names and hardware references. The first four appended voices are Chime 30 (VOX AC30 Top Boost), Orange Crown (Orange Rockerverb 50 MKIII), Bassman Valve (Fender Super Bassman) and Subway Clean (Mesa Subway D-800+). Match Chime, Silk ODS and Taste Punch add Matchless DC-30, Dumble Overdrive Special and EICH T900 target voices. Clone reference captures are labeled as clones; no exact EICH T900 NAM was found. Reference availability does not establish hardware fidelity. Short model names and hardware reference names identify the intended character of independent algorithms. They are not licensed hardware replicas or endorsements. Choose the head/cab first, then gain and EQ. LOAD or drop a WAV/AIFF onto a rig: mono/stereo, up to one second and 4 MB. Factory IRs are credited in THIRD_PARTY_NOTICES.md. Library entries must be Available to load; missing catalogue references are not audio. Add your own authorised folders or personal ZIP. The public installer does not contain restricted personal capture packs. Check MUTE, SOLO, POLARITY, cabinet bypass and frequency cuts when a rig sounds wrong.

Presets and compatibility

Help / reports / updates

SETTINGS → Manual / Bug report / Updates opens this offline manual, report tools and beta update checks. A useful report includes exact reproduction steps, expected/actual behaviour, OS, DAW/version, sample rate, buffer, models and routing. Review diagnostic data before submitting; no report is sent without your action. Avoid public attachments containing restricted personal IRs.

Updates discover compatible official beta release assets and verify download size/SHA256. Hash verification is integrity checking, not publisher identity signing. Save your work, close the host and app, then run the installer; an active audio process is never silently replaced. Unpublished prepared builds are not discoverable by the updater. Network failure should leave the current session usable.

Troubleshooting

No input meter: check driver, input channel, monitoring and OS microphone permission. Meter but no sound: check tuner mute, rig mute/solo, gate and output. Crackles: raise buffer, reduce oversampling, compare transpose bypass and instance count. Thin sound: check polarity, blend, doubler, mono compatibility and IR timing. Missing plugin: check standard VST3/AU folders, architecture and DAW rescan; remove obsolete manual copies after backing up presets. Missing IR: verify actual audio files, extraction, library folders and limits. Failed update: do not run incomplete downloads; retry from the official release.

DSP/UI/package tests are evidence for the covered cases, not hardware equivalence, universal DAW compatibility, signed/notarized distribution or real-instrument listening approval. Read the included verification logs and release notes for the tested scope.
