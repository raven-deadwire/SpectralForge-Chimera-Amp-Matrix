모델 명칭에 대하여: Chimera의 앰프·페달·랙은 표기된 하드웨어를 설계 참고점으로 삼은 독립 소프트웨어 모델입니다. 제조사와의 제휴·인증, 회로 단위 복제, 실물과의 측정 일치를 의미하지 않습니다. 원본명은 사용자가 음색의 출발점과 조작부의 의도를 이해하기 위한 reference caption입니다.

01 · 빠른 시작

  1. DAW와 기존 Chimera를 종료한 뒤 운영체제용 Open Beta 1.1 패키지를 설치합니다. Windows는 Standalone과 VST3 경로를 각각 선택할 수 있습니다.
  2. DAW에서는 오디오 트랙에 SpectralForge Chimera VST3/AU를 삽입하고 모니터링을 켭니다. Standalone에서는 Audio Settings에서 인터페이스와 입출력 채널을 지정합니다.
  3. 일반적인 기타/베이스 한 대는 MONO L로 시작합니다. 실제 스테레오 소스일 때만 STEREO를 사용합니다.
  4. 처음에는 Classic 모드에서 프리셋 하나를 고르고, INPUT 미터가 과도하게 피크하지 않도록 인터페이스와 INPUT gain을 맞춥니다.
  5. 헤드 → Cabinet/IR → PRE/POST 순으로 세부 음색을 맞춘 뒤 최종 OUTPUT으로 레벨 매칭합니다. 더 큰 소리가 더 좋은 소리처럼 들리는 착시를 피하려면 A/B 비교 시 출력 레벨을 맞추십시오.
  6. 기본 앰프 oversampling은 4×입니다. 실시간 연주에서 끊김이 있으면 2×/1×로 낮추거나 오디오 버퍼를 늘립니다.

기타 기본

Classic → Glass / Brit Edge / Tight 515 중 선택 → V30/Jensen IR → PRE 드라이브 → POST 공간계.

베이스 기본

Classic 또는 Matrix → Iron Tube / Solid Punch / Taste Punch → 필요 시 Cab bypass 또는 bass IR → 컴프레서로 피크 정리.

다운튜닝 / 확장음역

Matrix → LOW를 DI 중심으로 유지하고 MID/HIGH에 드라이브·앰프를 집중. LOW TAP 위치와 두 crossover를 먼저 정합니다.

02 · 신호 흐름과 라우팅 모드

INPUT → Gate / Transpose → 5-slot PRE → Rig(s) + Cabinet/IR → Merge → POST Gate(optional) → POST Rack → Doubler → OUTPUT

튜너는 Gate와 Transpose 이전의 원음을 읽습니다. A/B는 좌·우 채널이나 두 리그의 선택이 아니라 전체 사운드 상태 두 개입니다.

Matrix LOW의 핵심

LOW는 하나의 대역 안에서 DI와 선택한 amp/cab branch를 혼합합니다. LOW COMP는 저역의 다이내믹을 제어하고, BAND TONE과 LEVEL로 합산 전에 저역을 정리합니다. LOW TAP은 5-slot PRE 보드의 어느 경계에서 LOW로 분기할지를 정합니다. TAP 앞에 있는 페달은 LOW에도 실제로 적용되고, TAP 뒤 페달은 LOW에서 제외됩니다. 따라서 왜곡 페달을 TAP 앞으로 옮기면 LOW DI까지 왜곡됩니다.

권장 시작점: 저역 보존이 목적이면 Compressor/Envelope 정도만 TAP 앞에 두고, Fuzz/Drive/Modulation은 TAP 뒤에 두십시오. 반대로 실험적인 저역 질감을 만들 때는 gain pedal을 TAP 앞에 옮길 수 있습니다.

03 · 공통 기능

INPUT / OUTPUT플러그인 내부의 입출력 trim과 미터입니다. 인터페이스 입력 자체의 클리핑은 여기서 복구할 수 없습니다. OUTPUT은 최종 loudness matching에 사용합니다.
MONO L / STEREOMONO L은 왼쪽 입력을 복제해 내부 스테레오 경로에 공급합니다. STEREO는 두 입력 채널을 유지합니다.
GateThreshold는 문이 닫히는 기준, Hold는 신호가 기준 아래로 내려간 뒤 유지 시간, Release는 감쇄 속도입니다. 서스테인이 잘리면 Threshold를 낮추거나 Hold/Release를 늘립니다.
POST GATE연주 검출은 깨끗한 입력을 사용하고, 실제 감쇄는 리그/캐비닛 합산 뒤 POST 공간계 전에 적용합니다. 앰프 시뮬의 히스를 연주 사이에 줄이는 데 유리하지만 연주 중 발생하는 히스를 제거하는 노이즈 리덕션은 아닙니다.
Transpose−12~+12 semitone polyphonic pitch shift. 활성 시 추가 latency가 발생하며 호스트에 보고됩니다. 짧은 어택·복합 코드에서는 아티팩트가 생길 수 있습니다.
Tuner / AUTO MUTE입력 원음을 읽는 chromatic tuner. A4 기준 조절 가능. AUTO MUTE를 켜면 튜닝 중 최종 출력이 음소거됩니다.
Oversampling앰프 품질을 1× / 2× / 4× / 8×로 선택합니다. 높을수록 nonlinear aliasing 억제에 유리하지만 CPU 사용량이 증가합니다. 기본 4×.
Doubler짧고 변조된 wet delay로 스테레오 폭을 만듭니다. 모노 합산 시 위상/톤이 달라질 수 있으므로 믹스에서는 mono check를 권장합니다.
TAP / BPM / HOST수동 BPM, 탭 템포, 호스트 템포 추종. Delay SYNC는 quarter-note 기준으로 동작합니다.
CLICK연습용 4/4 metronome. DAW transport/bar 위치에 동기화되는 기능은 아닙니다.
MIDI Learn선택한 컨트롤에 다음으로 수신되는 MIDI CC를 할당합니다. Standalone은 MIDI input을 지정하고, 플러그인은 DAW에서 MIDI를 라우팅합니다.
A/B / COPYA와 B에 전체 사운드를 저장하고 전환합니다. COPY는 현재 상태를 반대 슬롯으로 복제합니다. 자동 loudness match는 하지 않습니다.
CPU AVG / PK전체 PC CPU가 아니라 Chimera audio callback이 block deadline에서 소비한 비율입니다. PK가 지속적으로 높다면 oversampling/효과 수/버퍼를 조정합니다.

04 · PRE — 5-slot pedalboard / 39 models

PRE에는 정확히 5개 슬롯이 있습니다. 한 슬롯의 모델을 교체해도 다른 슬롯의 parameter owner와 상태는 분리됩니다. 모델 선택, 복제, 삭제, 순서 변경과 각 모델의 bypass를 지원합니다. Empty는 모델 수 39종에 포함하지 않습니다.

구형 프로젝트는 기존 Legacy PRE 상태를 보존할 수 있으며, 새 5-slot 보드를 편집하면 새 엔진을 사용합니다. 구조 변경(모델 교체·재배열·LOW TAP 이동)은 재생 중 click-free를 보장하지 않으므로 중요한 세션에서는 transport를 정지한 뒤 편집하는 것을 권장합니다.

06 · Cabinet / IR

Cabinet 처리는 각 amp lane 내부에서 Amp → IR → Merge 순서로 동작합니다. Classic은 한 개, Dual은 두 개, Matrix는 LOW amp branch와 MID/HIGH에서 각각 필요한 IR을 선택할 수 있습니다.

  • CAB: 설치된 factory/user IR을 직접 선택합니다. BYPASS는 cab convolution만 우회합니다.
  • LOAD / Drag & Drop: WAV/AIFF IR을 lane에 불러옵니다. 현재 loader는 최대 1초·4 MB 범위를 기준으로 사용합니다.
  • IR LIBRARY: speaker size, mic, position, creator 등 catalog metadata로 검색/필터링합니다. “Missing” catalog row는 메타데이터만 있고 실제 WAV가 설치되지 않은 상태입니다.
  • LOW CUT / HIGH CUT: cab 이후 대역을 정리합니다. Matrix에서는 lane crossover와 겹쳐 지나치게 좁아지지 않도록 확인합니다.
  • MUTE / SOLO / POLARITY: 두 리그 또는 세 밴드의 합산 문제를 진단하는 데 사용합니다.
  • Project recall: user IR 오디오는 프로젝트/A·B 상태에 포함되므로 원본 파일을 이동해도 저장된 세션의 recall을 유지하도록 설계되어 있습니다.

공개 Beta 1.1에는 재배포 가능한 factory IR 두 개와 reference metadata가 포함됩니다. 개인 Raven IR 또는 외부 TONE3000 캡처는 공개 설치 파일에 포함되지 않으며 사용자가 권한을 가진 파일을 직접 가져와야 합니다.

추천 preset 수정 순서

  1. 목적에 가장 가까운 preset 선택.
  2. INPUT와 Gate를 실제 악기에 맞춤.
  3. 앰프/IR을 먼저 확정.
  4. Classic은 amp drive/EQ, Dual은 두 rig Level/Blend 또는 crossover, Matrix는 LOW TAP와 두 crossover를 먼저 조정.
  5. PRE의 gain staging을 맞추고 POST로 마감.
  6. A를 기준으로 COPY→B 후 한 요소만 바꾸어 level-matched 비교.

09 · 실전 톤 메이킹 예시

멜로딕 데스 / 타이트한 다운튜닝 기타

Classic에서는 Tight 515 → V30 계열 IR → Green Drive 또는 Yellow Asym을 기준으로 잡습니다. Drive pedal은 gain 자체보다 low-end 정리와 amp input push에 사용하고, amp gain을 지나치게 올리지 않습니다. Dual에서는 Tight 515를 중심에 두고 Wide Rect 또는 Blue Storm을 낮은 비율로 섞어 폭을 추가합니다.

5/6현 베이스 — clean low + driven mids

Matrix에서 첫 crossover를 약 120~200 Hz 범위의 시작점으로 두고 LOW는 COMP와 DI 중심, MID는 Modern Bass/Micro Bass drive, HIGH는 Solid Punch/Taste Punch 계열로 어택을 정리합니다. LOW TAP은 gain pedal보다 앞에 두는 것이 일반적인 출발점입니다. 각 밴드 level을 solo로 정한 뒤 전체 합산에서 polarity/phase를 확인합니다.

클린 / 앰비언트 기타

Glass 또는 Prism Chime을 낮은 drive로 사용하고 Optical compression으로 피킹을 정리합니다. POST Dimension → Tape Echo → Concert Hall 순서에서 modulation과 reverb mix를 작게 시작해 누적 과다를 피합니다.

리드 톤

Liquid Lead / Silk Lead / Hot Lead가 출발점입니다. Gold Drive는 gain을 크게 올리기보다 attack과 harmonic density를 보강하는 방향으로 쓰고, POST delay와 plate를 추가합니다. 솔로 음량을 실제로 올려야 할 때는 amp 앞 boost만 믿지 말고 lane Level 또는 최종 OUTPUT을 사용합니다.

10 · Diagnostics / CPU / Latency

SETTINGS → Review / copy / save diagnostics...에서 주요 처리 단계의 RMS/Peak, routing, Transpose, oversampling, 보고 latency와 audio callback AVG/PK를 확인할 수 있습니다. 이 수치는 LUFS나 전체 시스템 CPU가 아닙니다.

  • 레벨이 갑자기 줄었을 때: INPUT_TRIM → PRE → RIG_GATE → POST → OUTPUT 순으로 어느 단계에서 감쇄가 시작되는지 확인합니다.
  • Transpose: 0 semitone/비영점과 On/Off를 따로 비교합니다. host-reported latency가 맞는 것과 pitch quality가 좋은 것은 별도 문제입니다.
  • Spectral Octaver: 해당 slot에만 약 43~46 ms의 frame delay가 추가됩니다. bypass도 정렬을 위해 그 delay를 유지하며, 완전히 제거하려면 해당 slot을 Empty로 바꿉니다.
  • CPU peak: 8× oversampling, 여러 nonlinear pedal, convolution, poly pitch를 함께 쓰면 크게 늘 수 있습니다. tracking 단계에서는 2×/4×로 낮추고 최종 render에서 상향하는 방법이 실용적입니다.
  • IR phase: 서로 다른 IR의 자연 onset/phase는 자동 time-align되지 않습니다. Dual/Matrix에서 저역이 사라지면 polarity와 IR 조합을 확인합니다.

11 · 문제 해결

증상확인 순서
입력 미터가 움직이지 않음오디오 인터페이스 입력 → DAW track input/monitor → MONO L/STEREO → Standalone Audio Settings 순으로 확인.
소리는 나는데 너무 작음INPUT → pedal output → amp/channel master → rig level → cab bypass/cuts → POST module output → master OUTPUT. 진단 보고서로 단계별 RMS 비교.
고게인에서 히스가 남음입력 Gate와 POST GATE를 구분. POST GATE는 연주 사이의 앰프 히스 감쇄에 유리하지만 연주 중 noise suppression 기능은 아님.
Matrix에서 저음이 얇음LOW solo → DI/AMP mix → LOW TAP → first crossover → polarity → LOW cab/IR → Band Tone/Level 순으로 확인.
Dual에서 저음이 사라짐두 IR의 polarity/onset, Blend, 각 rig Level을 확인. 서로 다른 IR은 자동 phase alignment하지 않음.
CPU가 치솟음Oversampling을 낮추고 Spectral Octaver/Transpose, convolution, modulation 수를 점검. 오디오 buffer 증가.
Pitch 사용 시 latency가 큼Transpose와 Spectral Octaver를 각각 끄고 비교. Spectral Octaver는 구조적으로 frame delay가 있음.
페달을 바꾸자 click이 남모델 교체/재배열/LOW TAP 이동은 transport를 정지한 뒤 수행. 구조 편집의 완전한 click-free 동작은 베타 보증 범위 아님.
Studio One에서 프로젝트 종료 후 멈춤Beta 1.1의 종료 자원 정리 수정이 포함됐지만 사용자 환경에서 해결 확정은 아님. 동봉된 STUDIO_ONE_TEARDOWN.md와 선택형 Trace-Chimera-Session 도구로 재현 상태 수집.
기존 프로젝트의 model automation이 달라짐구형 테스트 빌드의 normalized model-choice automation은 목록 확장으로 매핑이 달라질 수 있음. 프로젝트 사본에서 모델 선택 lane을 검토/재기록.

12 · Open Beta 1.1 범위와 알려진 한계

  • Windows 배포본은 publisher code-signing이 완료된 정식 상용 서명 상태가 아니며, macOS도 Developer ID 서명/공증 전입니다. 운영체제 경고가 나타날 수 있습니다.
  • 앰프·페달·랙의 hardware reference는 기능·톤 방향을 위한 설계 참고점입니다. 실물 DI/reamp 기반의 전 모델 fidelity certification은 완료되지 않았습니다.
  • Transpose와 Spectral Octaver는 latency와 transient/chord artifact가 있을 수 있습니다.
  • AW-3의 HUMAN/TEMPO 등 일부 원본 기능, Variable Mu의 독립 right-bank/SEP 등은 현재 production behavior로 구현되지 않았거나 비활성 표시됩니다.
  • PRE 구조 편집 중 click-free를 보증하지 않습니다.
  • 서로 다른 IR의 natural onset/phase를 자동 보정하지 않습니다.
  • Studio One 종료 hang은 코드상 종료 루프와 자원 정리를 수정했지만 사용자 실제 환경에서 완전 해결 확인 전입니다.
  • 이번 공개 베타는 무료이며 향후 유료화될 수 있고, 베타 종료 후 무료 지원 정책이 바뀔 수 있습니다.

13 · English Quick Reference

SpectralForge Chimera Open Beta 1.1 is a guitar/bass amp and effects suite with 23 amplifier models, a five-slot PRE board containing 39 pedal models, 21 POST rack models and 31 factory starting presets.

  • Classic: one full-range amp/cab rig.
  • Dual Blend: two full-range rigs mixed together.
  • Dual Crossover: two LR4 frequency bands feeding independent rigs.
  • Matrix: LOW/MID/HIGH bands; LOW offers compression and DI/amp blending while MID/HIGH use independent rigs.
  • LOW TAP: selects the position in the five-slot PRE board where Matrix LOW branches. Pedals before the tap also affect LOW.
  • Signal path: Input → Gate/Transpose → PRE → Rig/Cab → Merge → optional Post Gate → POST → Doubler → Output.
  • Important beta limits: hardware-reference names do not imply licensed or verified hardware replicas; poly pitch can add latency/artifacts; structural pedalboard edits are not certified click-free during playback; different IRs are not automatically phase/time aligned; the reported Studio One shutdown hang still requires confirmation on the affected user system.
