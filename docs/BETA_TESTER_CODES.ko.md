# 베타테스터 연장 코드 발급 안내 (소유자용)

베타테스터에게 주는 코드는 베타 만료를 **무기한** 없앱니다. 한 번 입력하면 지금 베타와 **이후 모든 베타**(같은 키로 서명된 빌드)에 적용됩니다. 일반 사용자에게는 승인된 만료일(beta.2: 2027-03-31 23:59 KST)이 그대로 적용됩니다.

## 비밀키 보관

- 코드를 만들려면 소유자만 가진 **비밀키 파일**(`chimera-tester-key.private.json`)이 필요합니다.
- 저장소·클라우드 공유 폴더·메일에 올리지 마세요. 비밀키가 새면 누구나 코드를 만들 수 있고, 이미 배포된 빌드에서 막을 방법이 없습니다(새 키로 바꾼 빌드를 내야 함).
- 백업을 오프라인(USB 등) 두 곳에 두세요. 잃어버리면 새 코드를 발급할 수 없고, 새 키로 바꾸면 이미 나간 코드는 그 뒤 빌드에서 동작하지 않습니다.
- 저장소에는 공개키(`Source/TesterCodeKey.h`)만 있습니다.

## 코드 발급

Python 3.9 이상이 있는 컴퓨터에서 저장소 루트로 이동해 실행합니다.

```sh
python Tools/tester_code.py issue --private /안전한/경로/chimera-tester-key.private.json --name "테스터 이름"
```

- 출력된 `CHT1-...` 한 줄 전체가 코드입니다. 테스터 한 명에 코드 하나를 발급하세요(이름은 1–64자, 한글 가능).
- 코드에는 테스터 이름·발급일·코드 ID가 들어갑니다. 코드가 퍼지면 누구에게 준 코드인지 알 수 있습니다.
- 발급 기록(이름, 발급일, 코드 ID, 전달 방법)을 따로 남겨 두세요. 코드 자체를 저장소에 넣지 마세요.

발급한 코드를 확인하려면:

```sh
python Tools/tester_code.py verify --code "CHT1-..."
```

## 테스터에게 보낼 안내 (예시)

> Chimera 베타테스터 코드입니다. SETTINGS → **Enter beta tester code...** 에 아래 코드 전체를 붙여 넣고 APPLY를 누르세요. 이 컴퓨터에서는 지금 베타와 이후 베타가 만료되지 않습니다. 코드는 본인만 사용해 주세요.
>
> `CHT1-...`

- 컴퓨터마다 한 번 입력합니다. 같은 사람이 여러 컴퓨터를 쓰면 같은 코드를 각각 입력하면 됩니다.
- 이미 열려 있던 다른 Chimera 창은 SETTINGS의 **RECHECK CLOCK**을 누르거나 다시 열면 적용됩니다.
- 코드는 프로젝트 파일에 저장되지 않으므로, 프로젝트를 다른 사람에게 보내도 코드는 함께 가지 않습니다.

## 한계

- 오프라인 방식이라 **발급한 코드를 나중에 취소할 수 없습니다.** 문제가 생기면 새 키로 바꾼 빌드를 내야 하고, 그 경우 다른 테스터에게도 새 코드를 다시 발급해야 합니다.
- 기존 만료 정책과 같은 수준의 오프라인 제어이며, 변조를 막는 DRM은 아닙니다.
