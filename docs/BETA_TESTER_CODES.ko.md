# 베타테스터 연장 코드 발급 안내 (소유자용)

베타테스터에게 주는 코드는 베타 만료를 **무기한** 없앱니다. 한 번 입력하면 지금 베타와 **이후 모든 베타**(같은 비밀값으로 빌드한 버전)에 적용됩니다. 일반 사용자에게는 승인된 만료일(beta.2: 2027-03-31 23:59 KST)이 그대로 적용됩니다.

코드는 `CHT1-이름-확인문자6자리` 형태입니다(예: `CHT1-ZIEL-7K3Q9X`). 이름 뒤의 확인 문자는 비밀값으로 계산되므로 한 사람의 코드를 보고 다른 사람의 코드를 추측할 수 없습니다.

## 1. 처음 한 번: 비밀값 만들기와 등록

```sh
python Tools/tester_code.py secret --out "/안전한/경로/chimera-tester-secret.private.json"
```

- 출력된 64자리 16진수 값을 GitHub 저장소의 **Settings → Secrets and variables → Actions**에 `CHIMERA_TESTER_SECRET` 이름으로 등록합니다.
- 이 값이 없으면 릴리스 빌드(`build.yml`을 PR이 아닌 방식으로 실행)가 실패합니다. 값 없이 만든 빌드는 어떤 코드도 받지 않습니다.
- 비밀값 파일은 저장소·클라우드 공유 폴더·메일에 올리지 말고 오프라인 두 곳에 백업하세요.
- 비밀값을 바꾸면 이미 발급한 코드는 그 뒤 빌드에서 모두 동작하지 않습니다. 새 코드를 다시 발급해야 합니다.

## 2. 코드 발급

```sh
python Tools/tester_code.py issue --secret "/안전한/경로/chimera-tester-secret.private.json" --name ZIEL --name SINON
```

- 이름은 영문·숫자 2–16자입니다. 공백·점·하이픈은 빠지고 대문자로 바뀝니다(`Seo Mary` → `SEOMARY`, `K.loop` → `KLOOP`).
- 같은 이름은 언제 발급해도 같은 코드가 나옵니다. 발급 기록(이름, 날짜, 전달 방법)을 따로 남겨 두세요.
- 확인: `python Tools/tester_code.py verify --secret ... --code CHT1-ZIEL-XXXXXX`

## 3. 테스터에게 보낼 안내 (예시)

> Chimera 베타테스터 코드입니다. SETTINGS → **Enter beta tester code...** 에 `CHT1-ZIEL-XXXXXX`를 입력하고 APPLY를 누르세요. 이 컴퓨터에서는 지금 베타와 이후 베타가 만료되지 않습니다. 코드는 본인만 사용해 주세요.

- 대소문자는 상관없고, 확인 문자에서 O·I·L을 0·1로 잘못 입력해도 받아들입니다.
- 컴퓨터마다 한 번 입력합니다. 이미 열려 있던 다른 Chimera 창은 **RECHECK CLOCK**을 누르거나 다시 열면 적용됩니다.
- 코드는 그 컴퓨터의 사용자 설정에만 저장되고 프로젝트 파일에는 들어가지 않습니다.

## 4. 한계

- 오프라인 방식이라 **발급한 코드를 나중에 취소할 수 없습니다.** 코드를 받은 사람은 누구나 쓸 수 있으며, 코드에 이름이 들어 있어 출처는 알 수 있습니다.
- 비밀값은 릴리스 프로그램 안에 들어 있으므로 프로그램을 역분석하면 코드를 만들 수 있습니다. 기존 만료 정책과 같은 수준의 오프라인 제어이며, 변조를 막는 DRM은 아닙니다.
