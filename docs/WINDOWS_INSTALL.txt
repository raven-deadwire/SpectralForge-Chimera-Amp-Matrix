SpectralForge Chimera — Open Beta 1.3 (1.3.0-beta.1)
Windows 10/11 x64 설치 안내
==================================================

1. Studio One 등 모든 DAW와 Chimera를 종료하고 중요한 프로젝트를 복사해 보관합니다.
2. 받은 ZIP을 전체 해제하고 SpectralForge-Chimera-1.3.0-beta.1-win64-Setup.exe를 실행합니다.
3. VST3, 단독 실행 앱, 선택적 레퍼런스 도구를 선택합니다.
4. VST3의 기본 위치는 C:\Program Files\Common Files\VST3\SpectralForge Chimera.vst3입니다.
   다른 VST3 폴더를 선택했다면 DAW의 플러그인 검색 경로에도 추가하세요.
5. 단독 실행 앱의 기본 폴더는 기존 개발판 업그레이드를 위해
   C:\Program Files\SpectralForge\Chimera Amp Matrix 경로를 유지합니다.
   실행 파일과 시작 메뉴 이름은 SpectralForge Chimera입니다.
6. 시작 메뉴의 Manual 또는 앱 SETTINGS의 Manual에서 한국어/영어 오프라인 매뉴얼을 엽니다.
7. DAW를 다시 실행하고 필요하면 VST3를 재검색합니다.

이 베타 테스트 설치 파일은 퍼블리셔 코드서명 전입니다. 코드서명 또는 Windows Store
인증이 완료되었다는 의미가 아니며, 브라우저/Windows 경고가 나타날 수 있습니다.
다운로드 파일의 SHA256을 동봉된 해시와 비교하세요. 시스템 보안을 끄지 마세요.
바이너리는 MSVC 런타임을 정적으로 연결하므로 별도 VC++ 런타임 설치는 필요 없습니다.

업데이트 / 복구 / 제거
- 같은 Setup을 다시 실행하면 패키지 소유 파일을 복구합니다.
- 기존 AppId와 제거 항목을 유지합니다. 정확한 기존 실행 파일과 기존 VST3 바이너리만
  교체 대상이며 사용자 프리셋, IR과 프로젝트는 삭제하지 않습니다.
- 다른 폴더에 수동 복사한 이전 버전은 자동으로 삭제하지 않습니다.
- 이미 설치된 구성 요소를 선택 해제하는 것만으로 제거되지는 않습니다.
  필요한 경우 앱을 제거한 다음 원하는 구성 요소만 선택합니다.
- Windows 설정 > 설치된 앱 > SpectralForge Chimera에서 제거합니다.

IR
- 기본 IR 목록에는 출처와 이용 조건을 기록한 내장 factory IR 2개가 포함됩니다.
  상세 출처와 라이선스는 THIRD_PARTY_NOTICES.md와 IR_DISTRIBUTION.md에서 확인합니다.
- 재배포 근거를 확인하지 못한 외부·개인 참조 항목과 개발용 레퍼런스 음원은
  기본 목록과 배포 패키지에서 제외합니다.
- 직접 보유한 WAV/AIFF는 IR LIBRARY의 OPEN IR로 선택하거나 ADD FOLDER로 등록합니다.
  Setup 옆에 개인 IR 팩을 놓는 방식으로는 자동 등록되지 않습니다.
- 이미 등록한 사용자 IR 폴더와 프로젝트에 저장된 IR 오디오·메타데이터는 유지합니다.
  업데이트와 제거 과정에서 개인 IR 파일과 프리셋을 삭제하지 않습니다.
- 48개 팩토리 프리셋은 새 modeled CAB 조합을 사용하며 개인 IR 파일을 자동 검색하지 않습니다.
- IR을 해당 리그의 CAB에서 선택해야 소리에 적용됩니다. Matrix LOW는 DI/AMP가
  0이면 깨끗한 DI만 출력하므로 캐비닛 음색을 들으려면 AMP 비율을 올립니다.

호환성과 검수
- VST3/제조사/플러그인 고유 ID는 유지합니다.
- 기존 프리셋의 이름·ID·순서와 저장된 CAB 선택 값은 유지합니다.
  미공개 8×10 모델은 6×10으로 대체됩니다. 사용자가 불러온 8×10 IR은 변경하지 않습니다.
- 자동 DSP/UI/설치/복구/제거 검사 결과는 동봉된 Verification.txt와 CI 보고서에 있습니다.
  실제 악기 청취, 모든 인터페이스/DAW 조합 통과를 뜻하지 않습니다.
- SETTINGS의 Bug report에서 재현 단계와 환경을 정리하고 내용 확인 후 제출합니다.
- 업데이트는 공식 베타 릴리즈를 확인하고 크기/SHA256을 검증합니다.
  공개 전 준비 파일은 아직 업데이트 서버에 게시된 버전이 아닙니다.

English
Extract the ZIP and run SpectralForge-Chimera-1.3.0-beta.1-win64-Setup.exe after
closing the host/app. Setup defaults to Common Files\VST3 for the x64 VST3 and
the stable legacy application folder for SpectralForge Chimera.exe. Add a custom
VST3 folder to your host's scan paths. Start Menu includes an offline
Korean/English Manual shortcut. Reinstall
to repair package files. Uninstall keeps personal presets and IRs. Standalone,
VST3 and reference renderer statically link the MSVC runtime.

The beta installer is unsigned. Hash integrity checks do not establish publisher
identity. The default IR library contains two attributed factory IRs. Public
packages exclude unapproved reference catalogs, private captures and research
audio. Use IR LIBRARY / OPEN IR or ADD FOLDER for your own WAV/AIFF files, then
select them in the desired rig. A personal pack placed beside Setup is not
automatically imported. Registered user folders and saved project IR audio and
metadata remain available. Factory presets do not search for private IR files.
See MANUAL.html, INSTALLATION.md and OPEN_BETA_RELEASE_NOTES.md for full details.
