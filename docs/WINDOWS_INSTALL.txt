SpectralForge Chimera — Open Beta 1.0 (1.0.0-beta.1)
Windows 10/11 x64 설치 안내
==================================================

1. Studio One 등 모든 DAW와 Chimera를 종료하고 중요한 프로젝트를 복사해 보관합니다.
2. SpectralForge-Chimera-1.0.0-beta.1-win64-Setup.exe를 실행합니다.
3. VST3, 단독 실행 앱, 선택적 레퍼런스 도구를 선택합니다.
4. VST3는 C:\Program Files\Common Files\VST3\SpectralForge Chimera.vst3에 설치됩니다.
5. 단독 실행 앱의 기본 폴더는 기존 개발판 업그레이드를 위해
   C:\Program Files\SpectralForge\Chimera Amp Matrix 경로를 유지합니다.
   실행 파일과 시작 메뉴 이름은 SpectralForge Chimera입니다.
6. 시작 메뉴의 Manual 또는 앱 SETTINGS의 Manual에서 한국어/영어 오프라인 매뉴얼을 엽니다.
7. DAW를 다시 실행하고 필요하면 VST3를 재검색합니다.

현재 공개 베타 패키지는 퍼블리셔 코드서명 전입니다. 코드서명 또는 Windows Store
인증이 완료되었다는 의미가 아니며, 브라우저/Windows 경고가 나타날 수 있습니다.
다운로드 파일의 SHA256을 동봉된 해시와 비교하세요. 시스템 보안을 끄지 마세요.
바이너리는 MSVC 런타임을 정적으로 연결하므로 별도 VC++ 런타임 설치는 필요 없습니다.

업데이트 / 복구 / 제거
- 같은 Setup을 다시 실행하면 패키지 소유 파일을 복구합니다.
- 기존 AppId와 제거 항목을 유지합니다. 정확한 기존 실행 파일과 기존 VST3 바이너리만
  교체 대상이며 사용자 프리셋, IR과 프로젝트는 삭제하지 않습니다.
- 다른 폴더에 수동 복사한 이전 버전은 자동으로 삭제하지 않습니다.
- 이미 설치된 구성 요소를 선택 해제하는 것만으로 제거되지는 않습니다.
  필요한 경우 앱을 제거한 다음 원하는 구성 요소만 선택합니다.
- Windows 설정 > 설치된 앱 > SpectralForge Chimera에서 제거합니다.

IR
- 공개 설치 파일은 이용 조건을 확인한 내장 factory IR과 문서를 포함합니다.
- IR LIBRARY의 출처 목록과 실제 음원 설치 상태는 별개입니다. Available 항목만 로드됩니다.
- 추가 베이스 IR은 공식 배포처의 파일을 가져오거나 사용 권한을 가진 IR 폴더를 등록합니다.
- 기존 개인 팩은 IMPORT PERSONAL ZIP / ADD FOLDER로 등록할 수 있습니다.
  개인 설치 묶음이 있다면 압축을 전체 해제하고 Chimera-Personal-IRs 폴더를
  Setup과 같은 위치에 둡니다. 공개 패키지 자체는 개인 IR을 재배포하지 않습니다.
- 설치된 개인 IR은 C:\ProgramData\SpectralForge\Chimera\IRs에서 보존됩니다.
- IR을 해당 리그의 CAB에서 선택해야 소리에 적용됩니다. Matrix LOW는 DI/AMP가
  0이면 깨끗한 DI만 출력하므로 캐비닛 음색을 들으려면 AMP 비율을 올립니다.

호환성과 검수
- VST3/제조사/플러그인 고유 ID는 유지합니다.
- 앰프 8→15, PRE 계열 3→5 확장으로 이전 DAW의 정규화 모델 자동화가 달라질 수 있습니다.
  구형 프로젝트의 모델 선택을 확인하고 필요하면 자동화를 다시 기록하세요.
- 자동 DSP/UI/설치/복구/제거 검사 결과는 동봉된 Verification.txt와 CI 보고서에 있습니다.
  실제 악기 청취, 모든 인터페이스/DAW 조합 통과를 뜻하지 않습니다.
- SETTINGS의 Bug report에서 재현 단계와 환경을 정리하고 내용 확인 후 제출합니다.
- 업데이트는 공식 베타 릴리즈를 확인하고 크기/SHA256을 검증합니다.
  공개 전 준비 파일은 아직 업데이트 서버에 게시된 버전이 아닙니다.

English
Close the host/app before installation. Setup installs the renamed x64 VST3 in
Common Files\VST3 and SpectralForge Chimera.exe in the stable legacy application
folder. Start Menu includes an offline Korean/English Manual shortcut. Reinstall
to repair package files. Uninstall keeps personal presets and IRs. Standalone,
VST3 and reference renderer statically link the MSVC runtime.

The beta installer is unsigned. Hash integrity checks do not establish publisher
identity. Public packages exclude restricted personal capture data. Import
additional authorised IR files and select them in the desired rig. Preserve
important sessions and review model-selection automation from development builds.
See MANUAL.html, INSTALLATION.md and OPEN_BETA_RELEASE_NOTES.md for full details.
