RavenForge Luthier Intelligence / Chimera Amp Matrix

이번 빌드 변경
- RavenForge 배경 위에 모델별 페달/헤드/캐비넷/랙 이미지를 적용합니다.
  페달과 랙은 고정 직사각형 안에서 원본의 재질·패널·노브 특징을 재해석합니다.
- PRE: 컴프레서/엔벨롭/퍼즈/부스트/드라이브 각 5종, 총 25종입니다.
  POST 21종을 포함해 이펙트 모델은 총 46종입니다.
- 새 인스턴스의 PRE 기본 순서: 엔벨롭 -> 컴프레서 -> 퍼즈 -> 부스트 -> 드라이브.
  TOUCH는 엔벨롭 우선, SUSTAIN은 컴프레서 우선입니다. 기존 프로젝트는 이전 순서를 유지합니다.
- CAB 메뉴에서 설치된 IR을 직접 선택할 수 있습니다. IR LIBRARY에서는
  설치 상태, Bass/인치/마이크 등을 확인합니다. 파일 없는 목록은 로드할 수 없습니다.
- Matrix LOW: COMP -> DI와 선택한 앰프/CAB 병렬 혼합. DI/AMP 기본값 0% AMP.
  헤드 드라이브는 Matrix LOW에서 0으로 고정되고 숨겨짐. Classic/Dual 설정은 보존.
- 게시자 이름: RavenForge Luthier Intelligence. 현재 배포본은 서명 전 테스트 빌드.

개인 IR 포함 설치 묶음
1. Chimera-Windows-Installer.zip 전체를 새 폴더에 압축 해제하세요.
2. Setup EXE와 Chimera-Personal-IRs 폴더가 같은 위치에 있는지 확인하세요.
3. 그 위치에서 Setup을 실행하면 WAV 13개와 메타데이터가 함께 설치됩니다.
   EXE만 따로 옮기거나 압축 파일 내부에서 EXE만 실행하지 마세요.
4. 앱을 열고 CAB 메뉴 또는 IR LIBRARY에서 원하는 IR을 선택하세요.
   전체 개인 팩이 설치되면 기본 2개 + 개인 13개 = 15개를 사용할 수 있습니다.
   기존 개인 폴더를 더 등록했다면 표시 수는 15개보다 많을 수 있습니다.

개인 13개 구성: V30 3개, Fullback 1개, 베이스 2개, Karnivore 7개입니다.
베이스는 Ampeg 8x10/MD421과 1970 Bassman CTS 2x15/SM57입니다.
Karnivore의 마이크 표기는 파일명 기반이며, 미공개 수음 위치·거리·각도는 추정하지 않습니다.

이미 앱이 설치되어 있다면 IR LIBRARY > IMPORT PERSONAL ZIP에서 최신
Chimera-NAM-IR-personal.zip을 선택해 WAV 13개를 가져올 수 있습니다.
또는 IR 전용 ZIP을 전체 압축 해제한 뒤 ADD FOLDER로 Chimera-Personal-IRs를
등록하세요. 가져오기는 NAM 파일을 무시합니다. 이전 개인 ZIP에는 Karnivore가 없습니다.
가져온 IR은 다음 실행, 새 프로젝트와 VST3/Standalone에서도 유지됩니다.
설치/등록 후 CAB 메뉴에서 선택하거나 IR LIBRARY의 LOAD INTO RIG를 눌러야
해당 레인의 소리에 적용됩니다. Matrix LOW는 DI/AMP를 올려야 CAB 신호가 섞입니다.

GitHub의 공개 Setup 단독 파일에는 기본 IR 2개와 목록만 포함됩니다.
그 파일만 설치한 상태에서 목록의 IMPORT REQUIRED 항목이 보이는 것은
추가 WAV가 설치되었다는 뜻이 아닙니다. 위의 개인 전체 묶음이나 가져오기가 필요합니다.

Chimera Amp Matrix 1.0.0 TEST - Windows 설치 안내
===========================================================

1. Studio One 등 DAW와 기존 Chimera 실행 창을 모두 닫습니다.
2. 전체 ZIP을 해제한 폴더에서 Chimera-Amp-Matrix-1.0.0-test-win64-Setup.exe를 실행합니다.
3. 설치할 항목을 선택합니다. 기본값은 VST3 + 단독 실행 앱 + 레퍼런스 도구입니다.
4. VST3는 C:\Program Files\Common Files\VST3\Chimera Amp Matrix.vst3 에 설치됩니다.
   이 경로는 DAW의 표준 64비트 VST3 검색 경로입니다.
5. 단독 실행 앱은 기본적으로 C:\Program Files\SpectralForge\Chimera Amp Matrix 에
   설치되며, 시작 메뉴의 SpectralForge 폴더에서 실행할 수 있습니다.
6. DAW를 다시 실행합니다. 목록에 없으면 플러그인 재검색을 실행합니다.

업데이트 / 복구
동일한 설치 프로그램을 다시 실행하면 설치한 파일을 덮어써 복구합니다.
다음 버전도 같은 설치 폴더와 제거 항목을 사용합니다.
이전 ZIP을 별도 경로에 풀었다면 그 복사본은 자동으로 삭제하지 않습니다.
DAW에서 같은 플러그인이 중복으로 발견되면 이전 복사본의 위치를 확인하세요.

제거
Windows 설정 > 앱 > 설치된 앱 > Chimera Amp Matrix에서 제거합니다.
설치 프로그램이 배치한 파일과 바로가기만 제거합니다.
개인 프리셋, 프로젝트, 다운로드한 IR 및 사용자 설정은 삭제하지 않습니다.
구성 요소 선택은 새 파일의 설치 여부를 정합니다. 이미 설치된 구성 요소를
빼려면 앱을 제거한 다음 필요한 항목만 선택하여 다시 설치하세요.

개인 IR
TONE3000 개인용 IR은 공개 실행 파일에 내장하지 않습니다. 개인 전체 설치 묶음의
별도 WAV 폴더를 자동 설치하거나 IMPORT PERSONAL ZIP / ADD FOLDER로 등록합니다.
설치된 개인 IR은 C:\ProgramData\SpectralForge\Chimera\IRs에 보관됩니다.
직접 가져온 IR과 추가 폴더는 사용자 라이브러리에서 관리합니다.
NAM은 외부 검증용 기준 데이터이며 현재 플러그인의 실시간 로딩 형식은 아닙니다.

기존 테스트 프로젝트의 모델 자동화
저장된 모델 번호 0~2는 기존 모델을 유지합니다. 다만 PRE 모델 선택지가 3개에서
5개로 늘면서 DAW가 저장한 정규화 모델 자동화 값의 해석이 달라질 수 있습니다.
이전 테스트 빌드에서 모델 변경 자동화를 사용했다면 선택 결과를 확인하고 다시 기록하세요.
일반 프리셋/프로젝트 상태 복원과 DAW 자동화 호환성은 별개입니다.

호환성 / 확인 범위
Windows 10/11의 64비트 x64용 빌드입니다. 32비트 DAW는 지원하지 않습니다.
Visual C++ 런타임을 정적으로 링크하여 별도 VC++ 재배포 패키지를 요구하지 않습니다.
설치 파일은 코드서명 전 테스트 버전입니다. 설치형이어도 Windows/브라우저의
게시자 또는 평판 경고가 사라진다는 의미는 아닙니다. 보안 기능을 끄지 마세요.
SHA256은 함께 제공하는 .sha256.txt와 PowerShell Get-FileHash로 비교할 수 있습니다.

English
Extract the entire private installer ZIP first. Keep Chimera-Personal-IRs beside
Setup: its 13 WAVs and sidecars install with the application. With the two embedded
factory IRs, the complete personal collection has 15 available captures. A bare
public CI Setup includes only the two factory audio assets and catalog metadata.
For an existing installation, import the updated personal ZIP or add its extracted
IR folder, then select an installed IR in CAB or use LOAD INTO RIG.

Close your DAW and Chimera before installing or updating. Setup installs the
x64 VST3 bundle in Common Files\VST3 and the standalone app in Program Files,
with Start Menu shortcuts and a Windows uninstall entry. Run Setup again to
repair its files. User presets, downloaded IRs and settings are preserved.
Component deselection does not remove an already-installed component: uninstall
first, then install the desired selection. Portable copies outside these paths
remain untouched. This unsigned test installer does not establish publisher
trust or SmartScreen reputation. The binaries use the static MSVC runtime.
The expanded PRE model choices retain old raw project indices, but normalized DAW
model-selection automation from older test builds may need to be re-recorded.
