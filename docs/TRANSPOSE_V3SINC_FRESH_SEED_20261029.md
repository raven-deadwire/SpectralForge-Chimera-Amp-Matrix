# v3-sinc 새 시드 검증 — 2026-10-29 KST

**대상.** 연구 후보 `corr40-split-v3-sinc`다. v3에서 출력 읽기만 16탭 Kaiser 윈도 sinc로 바꾼 엔진이다(`TRANSPOSE_UPSHIFT_SPLICE_NOISE_20261028.md`). 기준 엔진은 `corr40-split-v3`다.

**결론: 사전 등록한 여섯 기준 중 다섯은 통과했고, 고역 잔여 기준(P5)은 실패했다.**

- **지연과 검출 (P1–P4):** v3와 사실상 같다.
  - 검출은 792/792 렌더에서 같았다.
  - 저역 지연 차이는 최대 0.004ms였다.
  - 목표 판정(T1–T4)과 고정 PDC 계약을 모두 충족했다.
- **블록 분할 (P6):** 432경우 × 13가지 = 5,616개 비교에서 차이 0이다.
- **고역 잔여 (P5) — FAIL:**
  - 새 시험음에서 v3-sinc의 잔여 초과량 중앙값이 44.1kHz +9.4dB, 48kHz +7.5dB였다. 기준은 +2dB다.
  - v3 대비 개선(중앙값 20.1 / 16.6dB)과 "v3보다 나빠지지 않음" 조건은 충족했다.
- **실패 원인:** 기준을 잘못 잡았다. 기준 +2dB는 지난 연구의 기본음 27.5–55Hz 시험음에서 나온 값인데, 이번에는 27.5–330Hz로 범위를 넓혔다. 기본음이 높을수록 이상적 기준음의 바닥이 −64dB에서 −97dB까지 내려가서, 같은 출력이라도 초과량이 커진다(아래 표). 다만 판정은 바꾸지 않는다.
- **새로 찾은 것:** 44.1kHz, 기본음 107.086Hz, +1반음에서 v3와 v3-sinc 모두 고조파 사이 잔여가 고조파 대비 −25dB까지 올라간다. 보간과 무관한 엔진 수준의 문제이며 미해결로 남긴다.

제품 `Source/`와 엔진 코드는 바꾸지 않았다. 측정은 합성 입력만 썼다.

## 사전 등록

렌더 전에 커밋 `144e801`로 push했다(`preregistration.json`, `Tools/TransposeNext/v3sinc_validation.py`). 스크립트는 소스나 바이너리 해시가 바뀌면 실행을 거부한다.

**새 시드.** 지금까지 쓴 시드 25개와 겹치지 않는다.

- holdout: 52915 / 57735 / 61803
- 긴 음: 3606 / 4123 / 4472 (고정 PDC는 3606만)
- 고역 시험음 난수: 70711

**렌더러.** JUCE 8.0.8로 다시 빌드했다. 등록 전에 출력이 다음과 비트 동일함을 확인했다.

- v3: 사전 등록 렌더러(SHA256 `5625cb…`)
- v3-sinc: 2026-10-28 연구 빌드
- v4: `main` 빌드

**통과 기준 (모두 충족해야 함).**

| | 내용 |
|---|---|
| P1 | v3-sinc, 목표 정의 버전 2, 전체 입력과 새 입력만: T1 어택·T2·T4 PASS, T3 상한 안 |
| P2 | 모든 렌더에서 onset 재설정, 짝 맞춤, 저역 재설정이 v3와 같음 |
| P3 | 저역 지연 차이 최대 ≤ 0.05ms |
| P4 | 고정 PDC(L = 2.5ms, 이벤트 SNR ≥ 10dB): 표본률마다 \|어택 잔차\| 최대 ≤ 4.5ms |
| P5 | 새 밝은 지속음, 1–8kHz 고조파 사이 잔여 초과량. 44.1/48kHz는 v3-sinc 중앙값 ≤ +2dB이고 v3 대비 개선 중앙값 ≥ 5dB, 96kHz는 중앙값 ≤ +1dB. 모든 표본률에서 v3-sinc가 v3보다 1dB 넘게 나쁜 경우 없음 |
| P6 | 새 입력 전부에서 블록 분할 13가지 출력이 비트 동일 |

**P5 시험음.** 표본률마다 12개, 반음 ±1·±2로 모두 48경우다.

- 기본음: 27.5–330Hz 로그 균등
- 고조파 기울기: 1/h^0.5 ~ 1/h^1.5
- 위상: 무작위

지표는 지난 연구와 같다. 1–8kHz에서 고조파 밖(±f/4) 에너지를 고조파 에너지와 비교하고, 이상적으로 음정만 바꾼 음의 같은 값보다 얼마나 높은지를 본다. 한 가지만 바꿨다. 이상적 기준음이 입력과 같은 고조파 집합을 갖게 했다(지난 스크립트는 다운시프트 기준음에 입력에 없던 8kHz 근처 고조파를 넣었다).

## P5 실패 분석 (판정에 쓰지 않음)

**기본음별로 나누면** (중앙값; 잔여는 고조파 대비 절대값).

| 표본률 | 기본음 | 경우 | 이상적 바닥 | 잔여 v3 → v3-sinc | 초과량 v3 → v3-sinc |
|---|---|---:|---:|---|---|
| 44.1kHz | ≤ 60Hz | 16 | −64dB | −47 → −60dB | +17.9 → +3.1dB |
| 44.1kHz | 60–130Hz | 24 | −85dB | −51 → −71dB | +32.0 → +13.7dB |
| 44.1kHz | > 130Hz | 8 | −97dB | −47 → −76dB | +46.2 → +18.0dB |
| 48kHz | ≤ 60Hz | 16 | −62dB | −46 → −61dB | +15.7 → +1.1dB |
| 48kHz | 60–130Hz | 24 | −82dB | −51 → −70dB | +30.1 → +11.9dB |
| 48kHz | > 130Hz | 8 | −96dB | −54 → −81dB | +38.2 → +12.7dB |
| 96kHz | ≤ 60Hz | 16 | −48dB | −48 → −48dB | +0.1 → 0.0dB |
| 96kHz | 60–130Hz | 24 | −67dB | −58 → −67dB | +5.2 → +0.2dB |
| 96kHz | > 130Hz | 8 | −83dB | −73 → −81dB | +9.7 → +0.8dB |

- **v3-sinc는 잔여를 늘리지 않는다.** 96kHz ≤ 60Hz(이미 바닥 수준)를 빼면 모든 구간에서 줄였다. 고조파 대비 절대 잔여 중앙값은 44.1/48kHz 모두 −48 → −68dB다.
- **초과량이 커진 이유는 기준음 쪽이다.** 기본음이 높으면 고조파 간격이 넓어서 이상적 기준음의 고조파 사이 에너지가 거의 0이 된다. 그래서 같은 −70dB 잔여라도 초과량은 +10dB를 넘는다.
- **sinc 뒤에 남는 잔여** (−70~−80dB)는 Kaiser β 8의 저지대역 감쇠와 4096 위상 양자화 수준이다. 이 검증에서는 원인을 따로 나누지 않았다.
- **지난 연구 범위(≤ 60Hz)만 봐도** 44.1kHz는 +3.1dB로 +2dB 기준을 넘는다. 48kHz는 +1.1dB로 기준 안이다.
- **기준을 잘못 정했다.** 지난 연구의 기본음 범위에서 나온 기준을 넓은 범위에 그대로 썼다. 다음 검증에서는 절대 잔여(고조파 대비)로 기준을 정하거나, 기본음 범위별로 기준을 나눠야 한다. 이번 판정은 바꾸지 않는다.

**44.1kHz 107.086Hz +1반음 (새로 찾은 문제).**

- v3·v3-sinc 모두 고조파 사이 잔여가 고조파 대비 −24.8 / −24.6dB다. 같은 조건의 48kHz와 이웃 기본음(105, 106, 108, 110Hz)은 −67 ~ −75dB다.
- 시간 구간(0.5초씩)이나 고조파 위상을 바꿔도 −24 ~ −25dB로 일정하다.
- 잔여 peak는 고조파에서 +0.27f(약 31Hz) 떨어진 자리에 줄지어 있다.
- 고역 경로가 1주기씩 19번 접합했다. 108Hz에서는 4주기씩 6번이다(`SpliceTrace`, v3, 2026-10-28 연구 빌드). 지난 연구가 기타 A1에서 본 '잦은 1주기 접합'과 같은 계열로 보인다. 다만 그때(고조파보다 53dB 이상 낮음)보다 훨씬 크다.
- 보간과 무관하다. v3-sinc를 쓸지와 상관없이 따로 조사해야 한다.

## 의미

1. **지연·검출·블록 분할:** v3-sinc는 새 시드에서도 v3와 같은 결정을 내리고, 목표와 고정 PDC 계약을 그대로 충족한다.
2. **고역 잔여:** 사전 등록 기준으로는 FAIL이다. 그래서 이 검증만으로 v3-sinc가 v3를 대체한다고 결론 내릴 수 없다. 다만 데이터로 보면 v3-sinc가 v3보다 1dB 넘게 나빠진 경우는 없고(최대 +0.2dB), 실패는 기준을 잘못 정한 데서 왔다.
3. **다음 일:**
   - 고역 잔여 기준을 다시 정하고, 새 시드로 다시 검증한다(절대 잔여 기준 또는 기본음 범위별 기준).
   - 44.1kHz 107Hz +1반음의 −25dB 잔여(v3에도 있음)를 원인 분석한다.
   - 마커 꼬리 다시 읽기, T6 청취, 실제 DI 검증은 그대로 남아 있다.
