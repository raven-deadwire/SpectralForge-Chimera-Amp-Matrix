# v3-sinc 고역 잔여 재검증 (측정 바닥 보정 기준) — 2026-10-29 KST

**대상.** `corr40-split-v3-sinc`의 1–8kHz 고조파 사이 잔여다. 같은 날 새 시드 검증(`TRANSPOSE_V3SINC_FRESH_SEED_20261029.md`)에서 고역 잔여 기준 P5만 실패했는데, 이번에 그 기준을 바로잡아 새 시드로 다시 검증했다. 기준 엔진은 `corr40-split-v3`다.

**결론: 사전 등록한 네 기준(R1–R4)을 세 표본률 모두에서 통과했다.**

- v3-sinc 순 잔여 중앙값: 44.1kHz −70.6dB, 48kHz −70.3dB, 96kHz −79.0dB (고조파 대비)
- v3 대비 개선 중앙값: 23.4 / 19.9 / 16.7dB
- v3보다 나빠진 경우: 없음 (가장 나쁜 경우 0.0dB)

지난 P5의 FAIL 판정은 그대로 둔다. 이번 결과는 그것을 대체하는 새 사전 등록 판정이다.

제품 `Source/`와 엔진 코드는 바꾸지 않았다. 측정은 합성 시험음만 썼다.

## 기준을 바꾼 이유

지난 P5는 "이상적 기준음보다 잔여가 얼마나 높은가(초과량)"를 봤다. 기본음이 높을수록 고조파 간격이 넓어져서, 이상적 기준음의 고조파 사이 에너지(측정 바닥)가 −48dB에서 −97dB까지 내려간다. 그래서 출력이 같아도 기본음이 높으면 초과량이 커졌다.

이번에는 **순 잔여**를 쓴다.

- 출력의 고조파 사이 에너지에서 이상적 기준음의 같은 에너지를 뺀다(에너지 단위).
- 그 값을 출력 고조파 에너지에 대한 dB로 나타낸다. 뺀 결과가 0 이하이면 −120dB로 둔다.
- 측정 바닥이 높을 때(낮은 기본음, 96kHz)는 바닥만큼 빠지고, 바닥이 낮을 때는 거의 그대로 남는다.

## 사전 등록

렌더 전에 커밋 `23682c8`로 push했다(`preregistration.json`, `Tools/TransposeNext/residual_validation.py`). 스크립트는 소스나 바이너리 해시가 바뀌면 실행을 거부한다.

**새 시드:** 86603. 고역 시험음에 쓴 적 없는 시드다(지난번 70711).

**시험음:** 표본률마다 16개, 반음 ±1·±2로 표본률당 64경우다.

- 기본음: 27.5–330Hz 로그 균등
- 고조파: 8kHz까지, 기울기 1/h^0.5 ~ 1/h^1.5
- 위상: 무작위
- 길이: 3초

지표 계산(Welch 32768점, 고조파에서 ±f/4 밖)은 지난 검증과 같다.

**렌더러:** 최신 `main`(`bba4a9d`)에서 다시 빌드했다. v3·v3-sinc 출력이 지난 검증 빌드와 비트 동일함을 확인했다. 새 스크립트로 지난 시드 70711을 다시 재면 지난 결과와 차이가 0이었다.

**통과 기준 (모두 충족해야 함).**

| | 내용 |
|---|---|
| R1 | 표본률마다 v3-sinc 순 잔여 중앙값 ≤ −60dB |
| R2 | 표본률마다 v3-sinc 경우의 90% 이상이 순 잔여 ≤ −50dB |
| R3 | 44.1/48kHz에서 v3 대비 개선 중앙값(v3 − v3-sinc) ≥ 10dB |
| R4 | 표본률마다 v3-sinc가 v3보다 1dB 넘게 나쁜 경우 없음 |

**기준을 정한 근거.** 결과를 이미 본 두 데이터를 개발용으로 썼다. 이 점을 등록 파일에도 적었다.

- 2026-10-28 연구의 시험음(기본음 27.5–55Hz)
- 2026-10-29 시드 70711

두 데이터에서 v3-sinc는 다음 값을 보였다. 그래서 이번 새 시드가 실제 판정이다.

- 순 잔여 중앙값: −67 ~ −82dB
- −50dB 이하 비율: 98–100%
- 44.1/48kHz 개선: 17–21dB
- v3 대비 가장 나쁜 경우: +0.2dB

## 보고 항목 (판정에 쓰지 않음)

- **지난 지표(초과량)로 보면:** v3-sinc 중앙값이 44.1kHz +9.4dB, 48kHz +8.3dB로 여전히 +2dB를 넘는다. 지난 P5를 이 시드에 적용해도 실패했을 것이다.
- **고조파 손실 중앙값:** v3 −0.15 / −0.13 / −0.05dB, v3-sinc −0.02dB(세 표본률).
- **측정 바닥 아래로 내려간 경우 (−120dB 처리):** 96kHz에서 v3-sinc 6경우, v3 3경우. 출력 잔여가 이상적 기준음의 바닥보다 낮았다는 뜻이다.
- **두 엔진 모두 −40dB를 넘은 경우:** 없음.

**96kHz 106.593Hz +1반음 (−47dB).** 이 경우 v3-sinc는 순 잔여 −47.1dB, v3는 −47.0dB였다(표의 96kHz 최대).

- 보간과 무관한 엔진 수준 잔여다.
- 같은 날 찾은 44.1kHz 107.086Hz +1반음(−25dB)과 비슷한 조건이다. 기본음이 약 107Hz이고 +1반음이다.
- 같은 기본음의 44.1/48kHz와 다른 반음에서는 −55dB 이하였다.
- 두 사례가 같은 원인인지는 아직 모른다. 원인 분석 과제에 이 사례를 함께 넣는다.
- 후속 (2026-10-30, `TRANSPOSE_SPLICE_EDGE_107HZ_20261030.md`): 두 사례는 같은 원인이었다. 고역 경로의 접합 탐색이 범위 끝에 걸린 최솟값을 그대로 썼기 때문이다.

## 의미

1. **v3-sinc의 고역 잔여 개선:** 측정 바닥을 보정한 사전 등록 기준으로, 새 시드에서 확인했다. 기본음 27.5–330Hz 전체에서 v3보다 중앙값 17–23dB 낮고, v3보다 나빠진 경우는 없다.
2. **v3-sinc의 지위:** 같은 날 새 시드 검증에서 지연·검출·고정 PDC·블록 분할(P1–P4, P6)은 이미 통과했다. 이번 재검증으로 고역 잔여도 통과했다.
   - 이로써 합성 입력 기준으로 v3를 대체할 근거가 갖춰졌다.
   - 대체 여부는 T6 청취와 CPU(+13–14%, 2026-10-28 측정) 판단이 남아 있다.
3. **남은 일:**
   - 기본음 약 107Hz +1반음 잔여(44.1kHz −25dB, 96kHz −47dB; v3에도 있음)의 원인 분석
   - 업시프트 마커 꼬리 다시 읽기
   - T6 청취, 실제 DI 검증
