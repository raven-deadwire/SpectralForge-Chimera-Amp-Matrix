## Undo/Redo

메시지 스레드에서 실행하는 Tone/Final 공용 EQ 편집 이력을 사용한다. 활성 뱅크에 관계없이 최신 EQ 작업을 되돌리며 다음 대상 뱅크를 UI에서 알 수 있어야 한다. 이력은 최대 64개 작업이며 프로젝트·프리셋·A/B에 저장하지 않는다.

- 그래프 mouse-down부터 mouse-up까지의 frequency/gain 변경은 한 작업이다. 해당 제스처에서 편집할 수 있는 파라미터마다 host begin/end gesture를 각각 한 번 보낸다. gain이 없는 필터는 frequency gesture만 연다.
- 수치 입력 확정, 종류 변경, 밴드 우회, 생성·삭제도 같은 명령 경로를 사용한다. 클릭만 한 작업과 실질적인 값 변경이 없는 작업은 이력에 추가하지 않고 redo도 버리지 않는다.
- Undo/Redo는 해당 작업에서 건드린 EQ 필드와 점유 상태만 복원한다. output, amp, IR, routing, pedal history와 호스트의 자동화 타임라인을 되돌리지 않는다.
- 새 EQ 호스트 자동화, MIDI 변경, 다른 소스의 EQ 파라미터 변경, 프리셋·프로젝트·전역 A/B 복원은 지역 이력을 무효화한다. 복원 값이 같아도 상태 복원은 이력 경계다.
- Tone/Final 어느 뱅크에서든 외부 EQ 알림이 오면 공용 이력 전체와 진행 중인 편집이 끊긴다. 같은 값을 반복 전달하는 외부 알림도 포함한다. 자동화 재생 중에는 지역 Undo를 유지하지 못할 수 있으므로 실제 DAW 모드별 편집 사용성을 확인한다.
- 외부 변경이 편집 또는 Undo/Redo 도중 도착하면 열린 gesture를 끝내고 남은 지역 쓰기를 중단한다. 최신 호스트 값을 이전 스냅샷으로 덮지 않는다.
- 같은 메시지 스레드에서 동기적으로 재진입한 호스트 쓰기도 외부 변경이다. 지역 쓰기 판별은 정확한 대상 파라미터와 예상 값으로 제한한다.
- 작업 시작 시 소유권 토큰을 먼저 읽고 before 값을 수집한 뒤 다시 검증한다. 스냅샷 수집 중 외부 변경이 오면 해당 작업을 시작하지 않는다.
- 창 숨김·종료, 슬롯 삭제·선택 전환, 프리셋·A/B 전환 후 열린 host gesture가 남지 않아야 한다.
- 아직 확정하지 않은 수치 입력은 선택·표시 대상·외부 소유권이 바뀌면 폐기한다. 동일한 수치의 다른 슬롯이나 같은 값의 프로젝트 복원에서도 이전 텍스트를 새 대상에 적용하지 않는다. 숫자 텍스트 편집 중에는 텍스트 편집기의 Undo 키를 우선한다.
- 플러그인은 DAW의 자동화 타임라인이나 DAW 자체 Undo 스택을 삭제·복원하지 않는다. EQ 작업의 한 번 Undo와 파라미터별 host gesture는 구분한다. 여러 파라미터의 sample-exact 원자적 일괄 적용을 주장하지 않는다.

## Snapshot Freeze

- 분석 소비자에 마지막으로 게시된 완전하고 유한한 IN/OUT 분석 프레임을 보존한다. 입력이 없는 상태에서 합성 프레임이나 부분 FFT를 만들지 않는다.
- raw/smoothed IN/OUT와 원래 FFT 크기·샘플레이트·smoothing 선택을 함께 고정한다. 오디오·파라미터·호스트 지연을 변경하지 않는다.
- frozen 상태에서 분석 값은 decay하지 않는다. 다른 EQ 뱅크의 편집·분석에는 영향을 주지 않는다.
- frozen 동안 LIVE·FFT 해상도·smoothing 변경을 잠근다. 화면 숨김이나 샘플레이트 변경에도 캡처된 프레임의 주파수 좌표를 바꾸지 않는다.
- 해제 시 캡처를 끈 상태로 요청 토큰을 발행하고 FIFO, 부분 입력 창, overlap, 이전 smoothing 및 이전 프레임 재사용 가능성을 제거한다. 요청을 관측한 오디오 콜백이 종료될 때까지 UI 타이머로 확인한다. 그 뒤 FIFO를 다시 비우고 캡처를 켜며, 새 샘플 N개로 완성한 유효 프레임 전까지 대기 상태를 표시한다.
- 해제 전에 실행 중이던 콜백은 자신이 진입할 때 읽은 과거 토큰만 확인하므로, 뒤늦게 게시한 이전 샘플이 새 분석에 들어갈 수 없다. 오디오가 정지되어 콜백이 오지 않으면 기다리며, 재개 후 첫 확인 콜백과 새 전체 분석창을 거쳐 표시한다. 오디오 스레드에 대기·잠금·할당을 추가하지 않는다. 분석기 자체의 FIFO 초기화와 실제 processor의 콜백 완료 경계를 함께 검증한다.
- 해제 대기 중 창을 닫고 다시 열어도 새 패널은 프로세서에 남아 있는 요청을 이어받는다. 프레임은 편집기 수명에 따라 없어지지만, 미완료 콜백의 배출 경계는 창 재생성으로 우회하지 않는다.
- NaN/Inf 또는 FFT overflow가 포함된 창은 정상 Freeze 원본으로 승격하지 않는다. 이후 유효 데이터로 정상 복구한다.
- UI에는 Freeze 상태와 캡처가 아직 없는 상태를 명확히 구분한다. 캡처 시점 이후 샘플레이트가 바뀌면 캡처의 원래 좌표를 유지한다.
- Freeze는 에디터 표시 상태다. DSP 프리셋·전역 A/B·Undo 이력으로 취급하지 않는다. 에디터를 닫고 새로 만들면 캡처도 사라진다. 같은 에디터 내 A/B·프리셋 변경은 FROZEN 표시 아래 기존 캡처를 유지한다.
- 최초 정상 프레임이 생기기 전에는 FREEZE 버튼을 비활성화한다. 정상 프레임이 이전 FFT/rate에서 생성된 경우 그 원래 좌표와 설정을 표시하고, 해제하면 사용자의 현재 live FFT/smoothing 선택으로 복귀한다.

## Peak hold (2026-11-04, Issue #53)

- 툴바의 **PEAK** 버튼으로 켜고 끈다. 기본값은 꺼짐이다. 켜면 빈 상태에서 시작하고, 끄면 지운다. "다시 시작"은 끄고 다시 켜는 것이다.
- 켜진 동안 새로 완성된 분석 프레임마다 화면에 그려지는 스펙트럼(smoothed IN/OUT power)의 bin별 최댓값을 올린다. 값은 내려가지 않는다.
- IN·OUT 표시가 켜진 쪽마다 얇은 선으로 그린다. 오디오가 멈춰 live 선이 사라진 뒤에도 남는다.
- Freeze 중, 화면 숨김·LIVE 재시작, idle decay, 샘플 누락 복구에서는 유지한다. 이것들은 이미 측정한 값을 바꾸지 않는다.
- FFT 해상도나 샘플레이트가 바뀌면 지운다. 같은 bin이 다른 주파수를 뜻하게 되기 때문이다. PEAK 자체는 켜진 채로 두고 새로 기록한다.
- Freeze와 같은 에디터 표시 상태다. 호스트 파라미터·프리셋·전역 A/B·Undo·프로젝트 저장에 들어가지 않는다. 오디오 처리는 바꾸지 않는다.
- 검증: `ChimeraEQSnapshotFreezeTests`의 `peakHold`(2048/4096/8192), `ChimeraGraphicalEQUITests`의 `peakToggle`(양쪽 EQ, 저장 상태 불변, 툴바 겹침·잘림 없음). 실제 DAW에서의 표시 확인은 별도다.

## 표시 범위와 커서 수치 표시 (2026-11-04, Issue #53)

- **표시 범위:** 그래프의 빈 곳을 오른쪽 클릭하면 EQ 세로 범위를 **±6 / ±12 / ±24 dB**(기본 ±24) 중에서 고를 수 있다. 바뀌는 것은 그리는 축척뿐이다. 밴드 값과 호스트 파라미터 범위(±24 dB)는 그대로다.
- 좁은 범위에서 화면 밖에 있는 밴드는 **그래프 가장자리에 붙여** 그리고, 그 위치를 눌러 선택할 수 있다. 드래그는 밴드의 **실제 값에서** 출발하므로, 눌렀다고 가장자리 값으로 바뀌지 않는다. 좁은 범위에서는 같은 픽셀 이동이 더 작은 dB 변화가 된다.
- 격자선은 범위의 1/4마다, 숫자는 1/2마다 표시한다.
- **커서 수치 표시:** 그래프 위에 마우스를 올리면 오른쪽 위에 커서 위치의 주파수(Hz/kHz)와 EQ dB를 표시한다. 분석기가 켜져 있거나 Freeze 중이고 데이터가 있으면, 화면에 표시 중인 스펙트럼의 그 주파수 레벨 dBFS도 함께 표시한다. OUT이 켜져 있으면 OUT, OUT이 꺼지고 IN만 켜져 있으면 IN이며, IN·OUT이 모두 꺼져 있으면 레벨을 표시하지 않는다(스펙트럼 그리기와 같은 조건). 드래그 중에도 갱신한다.
- 둘 다 PEAK·Freeze와 같은 에디터 표시 상태다. 파라미터·프리셋·A/B·Undo·저장 상태에 들어가지 않는다. 에디터를 다시 열면 ±24 dB로 돌아간다.
- 검증: `ChimeraGraphicalEQUITests`의 `displayRangeAndReadout`(양쪽 EQ). 축척별 노드 위치, 지원하지 않는 값 거부, 저장 상태 불변, 화면 밖 노드의 가장자리 표시와 실제 값 기준 드래그, 수치 문자열, 마우스 진입·이탈, 범위 전환 후 모든 호스트 파라미터·Undo/Redo·A/B 슬롯·편집 리비전 불변, 좁은 범위 드래그의 Undo/Redo를 확인한다. 같은 시험의 A/B 전환·공장 프리셋 구간에서 표시 범위가 유지되는지, `liveAnalyzer`에서 실제 오디오로 IN만·OUT만·둘 다·둘 다 끔·LIVE 끔·Freeze(토글 조합 포함, 고정 프레임에서 값 불변) 상태의 수치 표시를 확인한다. 오른쪽 클릭 메뉴 자체와 실제 DAW에서의 표시는 자동 검증 범위 밖이며, [EQ_READOUT_RANGE_HOST_CHECKLIST_20261105.ko.md](EQ_READOUT_RANGE_HOST_CHECKLIST_20261105.ko.md)로 실제 호스트에서 확인한다.

## 저역 확대 (주파수 보기, 2026-11-05, Issue #53)

- 그래프 빈 곳 오른쪽 클릭 메뉴의 **Frequency view**에서 가로 범위를 고른다: **Full 20 Hz–20 kHz**(기본), **Low 20 Hz–2 kHz**, **Bass 20–500 Hz**. 그리는 축척만 바뀌며 밴드 주파수 범위(20 Hz–20 kHz)와 호스트 파라미터는 그대로다.
- 확대 보기에서는 사이 격자선(30·40·60·70·80·150·300·700·1500 Hz)을 더하고, 숫자는 1-2-5 단위에만 붙인다. 분석기 선·Peak 선·응답 곡선·커서 수치 표시는 모두 같은 축척을 따른다.
- 보기 밖에 있는 밴드는 그래프 가장자리에 붙여 그리고 그 자리에서 선택할 수 있다. 드래그는 밴드의 **실제 주파수에서** 출발하므로 가장자리 주파수로 튀지 않는다. 세로 표시 범위와 같은 규칙이다.
- 가장자리 클릭 판정 수정: 그래프의 오른쪽·아래 경계는 판정 영역에서 빠져 있어서, 그 경계에 붙은 노드(좁은 dB 범위에서 −범위 아래로 내려간 밴드 포함)를 누를 수 없었다. 이제 그래프 둘레로 노드 반경(18 px)까지 누름을 받는다. 빈 곳 오른쪽 클릭 메뉴는 그래프 안에서만 연다.
- 에디터 표시 상태다. 파라미터·프리셋·A/B·Undo·저장 상태에 들어가지 않으며 에디터를 다시 열면 Full로 돌아간다.
- 검증: `ChimeraGraphicalEQUITests`의 `frequencyViewZoom`(양쪽 EQ). 보기별 노드 위치, 지원하지 않는 값 거부, 저장 상태 불변, 오른쪽 가장자리(5 kHz in 20–500 Hz)와 아래 가장자리(−18 dB in ±12 dB) 노드의 실제 값 기준 드래그, 확대 보기에서의 수치 표시를 확인한다. 메뉴 자체와 실제 DAW 표시는 자동 검증 범위 밖이다.

## 분석기 기울기 (Analyzer tilt, 2026-11-06, Issue #53)

- 그래프 빈 곳 오른쪽 클릭 메뉴의 **Analyzer tilt (pivot 1 kHz)**에서 **Flat**(기본), **3**, **4.5**, **6 dB/oct**를 고른다. IN/OUT 분석기 선과 PEAK 선을 1 kHz를 기준으로 옥타브당 그만큼 기울여 그린다(1 kHz 위는 올리고 아래는 내림). 고역으로 갈수록 내려가는 보통의 음악 스펙트럼을 평평하게 읽기 위한 것이다.
- 그리는 것만 바뀐다. 분석 자체, 오디오, 커서 수치 표시의 dBFS(측정값 그대로)는 바뀌지 않는다. 기울기를 켜면 그래프 왼쪽 아래에 `Analyzer tilt +4.5 dB/oct @ 1 kHz`처럼 표시해, 선의 높이가 측정 dBFS와 다르다는 것을 알린다. 오른쪽 dBFS 눈금은 1 kHz에서의 값이다. 선은 0 dBFS 위와 −96 dBFS 아래에서 잘린다.
- Freeze 중에도 고정된 프레임을 새 기울기로 다시 그린다.
- 에디터 표시 상태다. 파라미터·프리셋·A/B·Undo·저장 상태에 들어가지 않으며 에디터를 다시 열면 Flat으로 돌아간다.
- 검증: `ChimeraGraphicalEQUITests`의 `analyzerTilt`(양쪽 EQ). 실제 오디오로 만든 고정 프레임에서 100 Hz·400 Hz·1 kHz·4 kHz의 OUT 선과 PEAK 선이 기울기마다 정확히 `tilt × log2(f/1 kHz)` dB만큼 움직이는지(잘리는 점 제외), 수치 표시 불변, 지원하지 않는 값 거부, 메뉴 결과 처리(알 수 없는 ID 무시), 저장 상태 불변, Flat 복귀를 확인한다. 메뉴 자체와 실제 DAW 표시는 자동 검증 범위 밖이다.

## 여러 밴드 선택과 묶음 편집 (2026-11-07, Issue #53)

- **선택:** 노드를 **Ctrl+클릭**(macOS는 **Cmd+클릭**)하면 묶음에 넣거나 뺀다. 그래프 빈 곳을 드래그하면 상자 안의 노드를 고르고(Ctrl/Cmd를 누르고 드래그하면 기존 묶음에 더함), **Ctrl/Cmd+A**는 보이는 밴드를 모두 고른다. **Esc**는 선택된 밴드 하나만 남긴다. 묶음 밖 노드를 그냥 누르거나 밴드 선택 목록에서 고르면 새로 시작한다. 빈 곳을 클릭만 하면(상자 없음) 선택은 그대로이고, 더블클릭은 여전히 밴드를 추가한다. 빈 상자는 선택된 밴드 하나만 남긴다.
- **표시:** 묶음의 노드에는 고리를 두르고, 오른쪽 위 안내에 `3 bands selected  /  Delete removes  /  Esc clears`를 표시한다.
- **묶음 드래그:** 묶음의 노드를 잡고 끌면 모든 밴드가 **같은 주파수 비율과 같은 dB 변화**로 함께 움직인다. 각 밴드는 자기 범위(20 Hz–20 kHz, ±24 dB)에서 멈추고 나머지는 계속 움직인다. 게인이 없는 필터(HP/LP 등)는 주파수만 움직인다. Shift(미세)와 Alt/Option(축 고정)은 한 밴드 드래그와 같다. 드래그 전체가 **Undo 한 단계**이고, 호스트에는 필드마다 제스처 한 쌍이다.
- **휠(Q)과 삭제:** 묶음이 있으면 휠은 모든 밴드의 Q에 같은 배율을 곱하고, Delete/Backspace와 노드 오른쪽 클릭의 `Delete N Selected Bands`는 묶음 전체를 지운다. 둘 다 Undo 한 단계다. 아래쪽 밴드 컨트롤(주파수·게인·Q 숫자, 필터, 다이내믹)은 지금처럼 선택된 밴드 하나만 바꾼다.
- 선택 자체는 에디터 표시 상태다. 파라미터·프리셋·A/B·Undo·저장 상태에 들어가지 않는다.
- 검증: `ChimeraGraphicalEQGroupEditTests`(양쪽 EQ, `ChimeraGraphicalEQUITests --group-edit`). Ctrl/Cmd+클릭 추가·제거(선택 밴드를 빼면 다음 밴드로), Ctrl/Cmd+A, Esc, 상자 선택과 Ctrl/Cmd+상자, 빈 곳 클릭, 선택만으로 저장 상태 불변, 묶음 드래그의 비율 ×2·+4 dB와 묶음 밖 밴드 불변, 필드마다 제스처 한 쌍(6/6), 20 kHz에서 멈추는 밴드와 게인 없는 HP, Alt 축 고정, 휠 Q, 묶음 삭제와 Undo/Redo, 묶음 밖 클릭·밴드 목록으로 새로 시작을 확인하고 `eq-group-edit/group_bank*.png`를 남긴다. `ChimeraGraphicalEQEditingTests`의 `groupRemoval`은 여러 밴드 삭제가 Undo 한 단계로 튜닝까지 되돌아오는지, 없는 슬롯을 무시하는지 확인한다. 오른쪽 클릭 메뉴 자체와 실제 DAW·트랙패드 조작은 자동 검증 범위 밖이다.

## 밴드 순간 듣기 (SOLO, 2026-11-08, Issue #53)

- **쓰는 법:** 밴드 줄의 **SOLO** 버튼을 누르고 있거나, 그래프의 노드를 **가운데 버튼으로 누르고 있는 동안** 그 밴드 영역만 들린다. 놓으면 EQ 전체 소리로 돌아온다.
- **들리는 영역:** EQ를 거친 출력을 밴드 영역 필터에 통과시킨다.
  - Bell, Notch, Band pass: 밴드 주파수와 Q의 밴드 패스(Q는 0.5–8로 제한)
  - Low shelf, Low pass: 밴드 주파수의 로우 패스
  - High shelf, High pass: 밴드 주파수의 하이 패스
- **전환:** 들어가고 나올 때 15 ms 페이드로 클릭 없이 넘어간다. 다른 밴드로 바꿀 때는 먼저 페이드아웃한 뒤 바꾼다.
- **반드시 돌아오는 장치:**
  - 다음 경우에 에디터가 솔로를 끝낸다: 버튼이나 마우스를 놓을 때, 패널이 숨겨질 때, 다른 밴드를 고를 때, 밴드가 삭제될 때, 에디터가 닫힐 때.
  - 에디터는 솔로 중에 25 Hz로 신호(heartbeat)를 보낸다. 이 신호가 0.4초 동안 오지 않으면(에디터가 멈추거나 사라진 경우) DSP가 스스로 페이드아웃한다.
  - EQ 바이패스도 솔로를 끝낸다.
  - **오프라인 렌더(바운스)와 녹음 중에는 솔로를 적용하지 않는다.** 프로세서의 "printing" 상태(`isNonRealtime()` 또는 호스트 녹음)를 그대로 쓴다. 누르고 있는 솔로는 printing이 끝나면 다시 들린다.
  - heartbeat 경과 시간은 콜백 시작 시각(이미 CPU 계측용으로 읽는 값)으로 판단한다. 솔로 때문에 시계를 더 읽지 않는다.
  - 0.4초는 실제 시간 기준이다. 오디오 처리량 기준이 아니다. 만료 표시(`auditionedBand()==-1`)는 페이드가 시작될 때 나오고, 원래 출력으로 완전히 돌아오는 것은 15 ms 페이드가 끝난 뒤다.
  - prepare/reset은 솔로 필터와 믹스만 비운다. 에디터가 아직 누르고 있고 heartbeat가 살아 있으면 솔로는 다시 시작된다(누르고 있는 동안은 솔로라는 규칙).
  - 솔로가 끝난 뒤의 출력은 원래 EQ 출력과 비트 단위로 같다.
- 에디터 상태다. 파라미터·프리셋·A/B·Undo·저장 상태에 들어가지 않으며, 호스트 자동화에도 보이지 않는다.
- **검증:**
  - `ChimeraGraphicalEQTests`의 `bandSolo`(DSP):
    - 1 kHz Bell 솔로에서 대역 안/밖 전력비가 −7.7 dB에서 +7.6 dB로 바뀜
    - High pass 밴드 솔로가 차단 주파수 아래를 자름
    - 해제 후와 heartbeat 타임아웃 후 출력이 원래 EQ와 비트 단위로 같음
    - 페이드 중 최대 샘플 변화 0.0041(평소 톤 0.0042)
    - 바이패스가 솔로를 끝냄, 오디오 스레드에서 할당 없음
  - `ChimeraGraphicalEQGroupEditTests`의 `bandSoloUI`(양쪽 EQ):
    - SOLO 버튼 누름·떼기, 가운데 버튼 누름·떼기
    - 패널 숨김과 다른 밴드 선택으로 종료
    - 누르고 있는 동안 에디터가 heartbeat를 유지함
    - 저장 상태 불변
- **자동 검증 밖:** 실제 DAW에서의 청취, 마우스 가운데 버튼이 없는 트랙패드.

## 정확한 검증 기록

구현 소스와 자동 테스트 결과는 [실행 기록](evidence/eq-editing-oct23/README.md)에 보관했다. 정확한 e52976f 소스의 Linux Release 실행에서 관련 8개 CTest가 모두 통과했다(379.31초). 이는 기능·수치·상태 게이트의 결과이며 CPU/DAW/설치본 수용은 아니다. 실행 전 항목, 통과 항목, 실패한 최초 실행 및 수정 뒤 실행을 구분한다. 테스트 이름의 PASS만으로 설치본/물리 DAW 성능을 판정하지 않는다.

기존 #52의 반복 관측 macOS 비용 예외와 실제 고샘플레이트 callback/화면 수용 미평가 상태는 이 기능 작업으로 해제하지 않는다. 새로운 Snapshot 보관·유효성 검사에도 분석기 비용이 있으므로 기존 성능 회귀와 실제 장비의 지속 테스트가 필요하다.

이 구현으로 새 파일을 구버전 Chimera에 열었을 때의 파라미터 오디오 호환성이 예상되지만, 구버전 실행 파일과의 왕복을 직접 검증하지 않았다. 구버전 UI는 전체 12밴드를 표시하므로 표시 상태까지 동일하다고 주장하지 않는다.
