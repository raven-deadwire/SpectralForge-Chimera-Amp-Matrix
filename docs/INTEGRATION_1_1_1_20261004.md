## Verification scope

The implementation tree is `04cdb6dbe053e0a76c08517562308866101f0ee8`, published as commit `30c24b4abae384b6f03c92e0ba144dae8ff38906`. Local commit `87f21ad` has the same tree. Local testing uses Linux Release, JUCE 8.0.8, and optional UI probes enabled. CI builds the published commit separately.

All four signatures restore 3891 parameters and reproduce synthetic audio exactly (maximum difference 0). After synthetic-only level compensation, measured energies are 9.5094, 10.781, 11.3013 and 11.6673 respectively. These are not loudness targets or real guitar acceptance.

The processor unity checks cover Single, Dual and Matrix with both PRE paths. With amps/cabs disabled, output at 0 dB and gate disabled, measured gain error is approximately 0.002 dB. Existing output defaults remain -6 dB; portable factory presets commonly select -9 dB. GR reflects the compressor wet path, not total dry/wet or makeup gain.

The first full local run passed 13 tests; two executable files were unexpectedly empty and could not start. Relinking restored them, and both GateProcessor and IntegratedProcessor tests passed. The complete repeat passed all 15 configured tests in 112.41 seconds. See `Validation/Integrated111` for the full JUnit inventory, snapshots and evidence hashes. Local embedded diagnostic revision was configured before integration; exact commit-stamped platform binaries are verified separately in CI.

## Remaining acceptance

Fresh matched native-X11 UI probes ran 13 scenes, three repeats each, against main `fe365652`. RIGS idle message-thread CPU median fell from 69.68% to 2.04% of one core; POST idle from 74.42% to 2.09%; panel switching from 81.97% to 31.74%. Parameter snapshots were unchanged and synthetic audio hashes matched. This shared runner is not an isolated real-time environment; a short local relink also overlapped a baseline repeat.

Timing acceptance remains **BLOCKED**: tuner-scene median callback p99 increased from 826.201 to 906.091 microseconds and summed deadline misses from 7 to 23. Meter POST misses increased from 1 to 4. Several other scenes improved, but these short measurements cannot certify deadline non-regression. The baseline/candidate/comparison JSON files preserve all scenes.

- Pitch nominal FFT latency remains 2048 samples at 44.1/48 kHz and 4096 at 96 kHz (46.4/42.7/42.7 ms). The requested <=10 ms target is not achieved. Real isolated DI, stereo image, transient listening and live callback acceptance remain blocked.
- Gate real-DI hiss, palm mute and sustain listening, plus host automation acceptance, remain blocked.
- Commercial DAW project removal/close/reopen acceptance requires actual host execution. Windows harness CI results must be checked separately.
- The inherited UI CPU evidence is historical; it does not certify integrated audio callback timing.
- E670FE source captures, EQ ownership and calibration acceptance remain blocked under E1/E2.
