### 지연 한도를 줄이면 음정이 깨진다 (A20, A12 기각)

- 한도가 음의 한 주기보다 짧으면(B0 32 ms, E1 24 ms) 스플라이스가 한 주기씩 되돌아가 **출력이 원래 음정으로 돌아간다**(B0·E1에서 ±반음×100 cents 오차). E2(12 ms 주기)는 A20에서 맞고 A12에서 깨진다.
- 따라서 읽기 헤드 방식의 **지속 구간 지연은 최저음 한 주기 아래로 줄일 수 없다**(B0 약 32 ms). 10 ms 목표는 어택 지연으로 정의하고, 지속 구간은 가변(2–40 ms)으로 둔다. 고정 PDC로 보고할 수 있는 값은 아직 없다.
- A12 +12반음에서 출력이 NaN이 됐다: 업시프트 앵커(약 27 ms)가 12 ms 한도 밖이었다. `CorrelationPitch` 앵커를 `maximum-guard`로 제한해 고쳤다(E2 +12 렌더 유한 확인). 표의 A20/A12 +12 행은 수정 전 렌더라 무효다. A40 앵커는 한도 안이라 영향 없다.

## 추가: 겹침 구간 위상 일치 (`Tools/TransposeNext/PhaseLockPitch.h`)

`PolyPitch` 연구 사본에 저역 대역 위상 고정을 넣었다. 제품 `Source/PolyPitch.h`는 바꾸지 않았다.

- 저역 출력은 입력을 지연 D(t)로 읽은 것이므로, 입력 부분음 `cos(ω t + θ)`의 출력 위상은 `ω (T − D) + θ + ψ`다(ψ: LR4 위상, 저역·고역이 같다). STFT 분석 프레임 시작 위상 φ0에서 `θ + ψ = φ0 − ω (T − L)`이므로, 합성 위상을 **`φ0 + ω (L − D)`**로 두면 두 대역이 같은 위상이 된다. 다음 프레임에서 이 값은 `ω · ratio · hop`만큼 늘어 위상 보코더의 전파와 같다.
- 입력 주파수가 3 × 크로스오버(450 Hz) 아래인 bin만 고정하고, 그 위는 제품과 같은 위상 전파를 쓴다. 저역 엔진은 샘플별 읽기 지연을 내보낸다(`CorrelationPitch::process`의 `delayOut`).
- **D의 시점은 측정으로 정했다.** 프레임 첫 출력 샘플 T의 지연을 쓰면 대역 간 위상차가 `(1 − ratio) × 약 500샘플 × ω`로 남았다(−2: 56, −5: 129, +2: −59샘플, 시간 표준편차 0–3°). `D(T + L + hop/2)`로 외삽하면 −12 … +12반음 전체에서 위상차가 ±12° 이내이고 대부분 3° 이하다. 96 kHz에서도 같은 보정으로 ±12° 이내다. hop/2 항의 해석적 근거는 아직 없다(합성 창 기준점으로 추정).

## 정정: 위상 고정은 분해된 부분음에서만 작동한다 (`Tools/transpose_reanchor_probe.py`)

|---|---|---|
| 사인 165 Hz | −0.97 / **1.00** | 0.65 / **1.00** |
| 사인 82 + 165 Hz | −0.12 / −0.11 | −0.15 / 0.53 |
| 정상 하모닉 82 Hz (8배음) | −0.01 / 0.11 | 0.04 / 0.14 |
| 플럭 82 Hz | 0.01 / −0.04 | −0.13 / 0.22 |

- 10 ms STFT(480 창, 512 FFT)의 bin 폭은 약 94 Hz다. 크로스오버 영역의 베이스 배음은 기음 간격(41–110 Hz)으로 놓여 **한 bin에 둘 이상이 섞인다.** 위상 고정 공식 `φ0 + ω (L − D)`는 bin마다 부분음 하나와 그 순간 주파수를 가정하므로, 섞인 bin에서는 성립하지 않는다. 앞 절의 개선(−17 → −1.25 dB)은 **사인 하나에서만** 유효하다.
- 대신 하모닉 소재에서는 **체계적 노치도 없다.** 위상이 부분음·프레임마다 흩어져 지속 구간 합 결손은 0 dB 근처(무상관 합)다. LR4의 저역·고역 진폭 합은 크로스오버에서 각각 −6 dB이므로, 입력 대비로는 150 Hz 부근에서 **평균 약 −3 dB에 부분음마다 흩어지는 착색**이 된다. 사인 측정의 −17 dB는 고립 부분음의 최악 경우다.
- 재정렬 직후(입력 onset 뒤 5–30 ms) ρ는 −0.9 … +0.9로 출렁이지만, 지속 구간 자체가 무상관이라 재정렬만의 불연속으로 분리할 수 없다. **재정렬 위상 연구는 이 구조에서는 대상이 아니다.**
- **판정 정정:** AL9RA-LOCK은 AL10RA보다 낫다고 할 근거가 없다(하모닉 소재 ρ 차이 없음, 어택은 AL9 정렬 덕분). 위상 고정 코드는 연구 기록으로 남기고 후보에서 뺀다. 연구 후보는 다시 **AL10RA**(저역 어택 ≤10.5 ms, 음정 2.3 cents 이내, 크로스오버 평균 약 −3 dB의 무상관 착색)다.
- 겹침 구간을 정합하게 만들려면 그 구간을 엔진 하나가 맡아야 한다. 예: 겹침 구간 전체를 저역 읽기 헤드로 처리하고 크로스오버를 올리는 방식. 이때는 화음이 시간영역 엔진을 지나므로, 측정기 기음 추정에 의존하지 않는 화음 지표가 먼저 필요하다(파워코드 700 cents는 TIGHT·CLASSIC에서도 나와 추정기 모호성이 섞여 있다).

- 처음 본 스파이크(32 블록 p99.9 약 700 µs)는 **디노멀** 탓이다. 음 사이 무음에서 크로스오버 필터 상태가 감쇠하며 디노멀이 생기고 그 값이 STFT로 들어간다. 3 s 단일 파일(무음 뒤 감쇠 없음)에서는 TIGHT와 같았고(227 vs 238 µs), `ScopedNoDenormals`를 켜면 TIGHT와 같은 수준이 된다.
- 플러그인은 `Source/PluginProcessor.cpp:160`에서 `ScopedNoDenormals`를 쓰므로 호스트 안에서는 TIGHT와 비슷한 실시간 부담으로 본다. **제품으로 옮길 때는 FTZ에 기대지 말고 하이브리드 안에 디노멀 방지를 넣는다**(크로스오버 출력·필터 상태의 극소값을 0으로).
- CLASSIC의 32 블록 `over_half` 3600여 개는 제품 CLASSIC 자체(43 ms 창 FFT)의 특성이다.

**반음 자동화** (`automation_48k.json`; E2 지속음, 1.2 s에 반음 변경, 블록 64, `nodenormals`):
- 전환: −5→+2, −2→−12, +12→−12, 0→−5, −5→0, +7→+5
- 모든 전환에서 출력이 유한하다.
- 전환 직후 60 ms 피크는 직전 200 ms 피크보다 크지 않다(TIGHT −0.9 … −1.6 dB, AL10RA-800 −1.1 … −1.5 dB).
- 2 kHz 위 성분 피크(직전 RMS 대비)는 AL10RA-800 5.5–8.7 dB, TIGHT 5.6–14.1 dB로 하이브리드가 같거나 작다.

**남은 엔지니어링 과제**
- 하이브리드 내부 디노멀 방지.
- 0반음 전환 시 즉시 원음으로 바뀌는 경로의 크로스페이드. 현재 TIGHT와 같은 방식이고 측정상 비슷하다.
- 고정 PDC 보고 방식: 지속 구간 저역 지연이 가변이라 정해지지 않았다.

**디노멀 방지 반영.** `HybridLowBandPitch::process`가 직접 `juce::ScopedNoDenormals`를 켠다.
- 호스트가 FTZ를 켜지 않아도 32 블록 p99.9가 AL10RA-800 212–301 µs다(TIGHT 264 µs, 예산 초과 블록 6–15 vs 8).
- 출력은 이전 바이너리에 `nodenormals`를 켠 렌더와 비트 단위로 같다(5 조건).
- 이 절 이전의 하이브리드 원자료는 방지 없이 렌더했다. 같은 소재·모드 100 렌더를 다시 비교하면 72개는 같고, 27개는 1e-36 이하(디노멀 크기)만 다르다. 1개(클릭, AL10RA-150, +12)는 최대 0.058이 달라졌다. 무음 속 극소값이 감지·스플라이스 비교를 한 번 바꾼 것으로 보며, 판정 표의 수치는 바뀌지 않는다.

## 추가: 고정 지연 보고 설계

별도 문서 `docs/TRANSPOSE_HYBRID_LATENCY_CONTRACT.md`. 보고 지연을 STFT 창(10 ms)으로 두고 저역 어택을 양방향 모두 거기에 맞춘 계약 모드(probe 모드 39)에서, 피킹 어택 오차는 −0.5 … +2.3 ms다(팜뮤트 제외 ±0.7 ms). 피킹 없는 음 변화(레가토·해머온)는 계약 밖이다(레가토 −4 … +29 ms, 해머온 −16 … +29 ms).

레가토 재정렬 연구(probe 모드 40)는 `docs/TRANSPOSE_HYBRID_LATENCY_CONTRACT.md` §7. 레가토 중앙값 오차 +13.0 → +1.4 ms, 피킹 계약은 그대로, 아직 채택하지 않는다(감지율·+12 지연·C4 장3화음 오검출·해머온 측정 편향).
