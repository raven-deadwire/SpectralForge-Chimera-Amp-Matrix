# SpectralForge Chimera — Open Beta 1.5

**Version 1.5.0-beta.1 · Windows / macOS / Linux · 공개 베타**

공개된 1.4.1-beta.1(2026-11-18 KST) 이후 main에 통합된 작업을 묶은 베타입니다. 만료일은 1.4.0-beta.1, 1.4.1-beta.1과 같은 **2027-05-31 23:59 KST**입니다. 이 소스 그대로의 Windows·macOS·Linux 자동 검증을 통과하고, 아래 알려진 한계를 공개한 상태로 소유자가 공개를 승인해야 공개됩니다([후보 기록](RELEASE_1_5_0_CANDIDATE.md)). 안정판이나 엄격 검증 통과가 아닙니다.

선택 가능 모델 수(AMP 30, PRE 51, POST 39, CREATIVE 9, SYNTH 3)는 1.4.1-beta.1과 같습니다. 새 파라미터는 모두 기존 파라미터 뒤에 추가되어, 기존 파라미터의 ID·순서·범위·기본값은 그대로입니다. 자동 시험은 실제 악기 DI·DAW·청음 검증을 대신하지 않습니다.

## 기존 프로젝트에 영향이 있는 변경

**Metro Clean을 쓰는 프로젝트는 소리가 달라질 수 있습니다.** 아래 "Metro Clean 리모델"을 먼저 읽어 주세요. 그 밖의 변경은 저장된 프로젝트의 소리를 바꾸지 않습니다.

## 주요 변경

### POST 두 번째 슬롯

- **슬롯 2:** POST의 일곱 섹션(다이내믹스, 프리앰프, EQ, 모듈레이션, 딜레이, CREATIVE, 리버브)마다 독립된 두 번째 슬롯이 생깁니다. 모델, 컨트롤, ON 스위치, 상태를 슬롯 1과 따로 갖습니다. 예: 짧은 슬랩 딜레이와 긴 에코를 함께 쓰기.
- **기본값:** 두 번째 슬롯은 모두 꺼져 있습니다. 꺼진 슬롯은 건너뛰어 CPU와 지연을 더하지 않습니다.
- **POST 페이지:** 각 랙 줄의 제목 오른쪽에 "1 | 2" 스위치가 있습니다. 슬롯 2가 켜져 있으면 "2"에 초록 불이 들어옵니다.
- **신호 순서:** 순서 편집기의 POST 구간이 14블록이 됩니다. 기본 순서는 기존 순서 뒤에 슬롯 2들이 같은 섹션 순서로 붙습니다. ROUTING 그래프는 14블록을 세 줄로 보여 줍니다.
- **기존 프로젝트:** 슬롯 2가 모두 꺼진 채 기존 순서로 열리며, 오디오는 비트 단위로 같습니다(시험: 최대 샘플 차이 0).
- **이전 버전으로 되돌릴 때:** 슬롯 2를 앞쪽 일곱 자리 안에 배치해 저장한 프로젝트를 이전 버전에서 열면, 그 버전은 순서를 인식하지 못해 기본 순서로 엽니다.
- 새 파라미터 269개가 맨 뒤에 추가됩니다(ID 접두사 `slot2_`, 호스트 이름 끝에 "(slot 2)").

### POST 페이지에서 끌어서 순서 바꾸기

- POST 랙 줄의 왼쪽 그립(전원 표시등 아래 점 여섯 개)과 CREATIVE 스트립의 왼쪽 가장자리를 끌어 순서를 바꿉니다. 지금까지는 ROUTING 그래프와 PRE 보드에서만 끌 수 있었습니다.
- 다른 블록 위에 놓으면 그 자리로 옮겨집니다. Undo 한 단계이고 순서가 바뀔 때 클릭이 나지 않습니다. Escape, 자기 줄이나 블록 밖에 놓기, 단순 클릭은 아무것도 바꾸지 않습니다.

### Metro Clean 리모델 (기존 소리가 달라질 수 있음)

- **2채널:** 베이스 앰프 Metro Clean(모델 11)이 2채널이 됩니다. **MODERN**은 기존 Metro Clean을 잇는 채널이고, **CLASSIC**은 더 쉽게 드라이브가 걸리는 새 채널입니다. 출력단의 **O/D SYMMETRY**가 추가됩니다.
- **패널:** 공용 GAIN SWITCH HIGH/LOW·DEEP·BRIGHT·MUTE, 채널별 GAIN·HIGHPASS·BASS·MID·MID FREQ·TREBLE·VOLUME.
- **기존 프로젝트와 프리셋:** MODERN 채널로 열리고 저장된 노브 값은 그대로 읽습니다. 다음 부분에서 소리가 달라집니다.
  - **VOICING, HI MID, HI MID FREQUENCY:** 없어졌습니다. 값은 프로젝트에 남지만 소리에 쓰이지 않습니다. 기존 기본값의 VOICING(정오)은 550 Hz 부근을 약하게 깎고 있었으므로, 손대지 않은 프로젝트도 그만큼 달라집니다.
  - **HIGH PASS:** 노브 위치는 유지되지만 범위가 30–150 Hz(지수)에서 25–125 Hz(선형)로 바뀝니다.
  - **LO MID FREQUENCY → MID FREQ:** 노브 위치는 유지되지만 범위가 150 Hz–2 kHz(선형)로 바뀝니다.
  - **DEEP, EQ 모서리 주파수:** 새 설계를 따릅니다.
- **팩토리 프리셋:** Metro Clean을 쓰는 프리셋(Slap Studio, Wool Bass Fuzz, G+B Low Anchor, B+B 계열 등)은 MODERN으로 유지되며 MID FREQ를 기존 중심 주파수에 맞췄습니다. 기존 VOICING·HI MID 보정은 빠집니다.
- 직접 설계한 DSP이며 실제 앰프 측정에 맞춘 것이 아닙니다. 새 파라미터 48개가 뒤에 추가됩니다.
- 네이티브 엔진 이전에 저장한 프로젝트가 쓰는 레거시 엔진은 그대로입니다.

### 레퍼런스 헤드 26~30의 새 외관

- Crystal 120, Bluestack 100, Eightyfire, Fortress 103, Northlight의 헤드 그림을 사진 기반 셸로 바꿨습니다. 노브 줄의 상대 위치는 그대로이고 소리는 바뀌지 않습니다.

### Auto Set (새 단계는 모두 기본 꺼짐)

새 단계 8개는 AUTO SET 옆 옵션 버튼에서 켭니다. DI·청음 확인을 아직 거치지 않아 기본값은 꺼짐이며, 켜지 않으면 Auto Set 결과는 1.4.1-beta.1과 같습니다. 각 단계는 잠금·강도·UNDO AUTO를 따릅니다.

- **Dual Blend의 두 리그:** 앰프 게인과 톤(33단계), Presence와 Resonance(34단계), 앰프 채널 선택(35단계), GAIN 범위를 넘는 입력 트림(36단계).
- **Dual Crossover의 두 리그:** 앰프 게인(37단계), 앰프 채널 선택(38단계), 입력 트림(39단계).
- **Matrix의 MID·HIGH 레인:** 앰프 게인(40단계).

게인 단계(33·37·40)는 리그나 레인마다 듣는 패스가 따로 추가되어 듣는 시간이 늘어납니다. 자세한 규칙은 `docs/AUTO_SET_PHASE33.md` … `docs/AUTO_SET_PHASE40.md`에 있습니다.

### 시험, CI, 문서 (제품 동작 변화 없음)

- 실제 OBS 앱 시험 두 개가 macOS CI 러너의 타이밍 때문에 떨어지던 것을 손봤습니다. OBS 필터 코드는 1.4.1-beta.1과 같습니다.
- 릴리즈 게이트가 요구하는 E1 시험 합계를 이 버전의 파라미터·화면 수에 맞췄습니다.
- Windows AAX·설치기 코드 서명 안내서를 추가했습니다. AAX는 이 릴리즈에 들어 있지 않습니다.

## 알려진 한계

- 실제 기타·베이스 DI 청음과 Drop A 테이크 검증은 하지 않았습니다.
- 실제 DAW·오디오 장치 수용 시험은 하지 않았습니다.
- 퍼블리셔 서명과 macOS 공증은 없습니다.
- AAX는 포함되지 않았고 Pro Tools에서 검증하지 않았습니다.
- Metro Clean의 새 두 채널, POST 두 번째 슬롯, 1.4.1 이후의 새 Auto Set 단계는 자동 시험만 거쳤습니다. 실제 악기로 듣는 확인은 하지 않았습니다.
- 새 독일어·한국어 설명서 문구의 원어민 검토가 남아 있습니다.

실행하지 않은 검사는 통과로 보고하지 않습니다.
