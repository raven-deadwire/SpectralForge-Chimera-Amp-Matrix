# SpectralForge Chimera — Open Beta 1.4

**Version 1.4.0-beta.1 · Windows / macOS / Linux · 공개 베타**

공개된 1.3.2-beta.1(2026-10-18) 이후 main에 통합된 작업을 하나의 베타로 묶었습니다. 만료일은 **2027-05-31 23:59 KST**입니다. 정확한 소스의 Windows·macOS·Linux 자동 검증을 통과했고, 아래 알려진 한계를 공개한 상태로 소유자가 공개를 승인했습니다([후보 기록](RELEASE_1_4_0_CANDIDATE.md)). 안정판이나 엄격 검증 통과가 아닙니다.

로드맵의 1.3.3 Room Core부터 1.10 SYNTH와 2.0 통합 검사까지 먼저 구현된 기능이 이 베타에 들어갑니다. 버전 번호는 로드맵 작업창이 아니라 공개 순서를 따릅니다. 각 기능의 자동 시험은 실제 악기 DI·DAW·청음 검증을 대신하지 않습니다.

## 주요 변경

### 모델과 신호 경로

- **카탈로그:** 선택 가능 모델이 AMP 30, PRE 51, POST 39, CREATIVE 9, SYNTH 3(총 132)으로 늘었습니다. 기존 모델 순서와 저장값은 유지하고 새 모델은 뒤에 추가합니다. 프리셋은 48개입니다.
- **PRE 확장:** 두 묶음으로 PRE를 12종 추가합니다.
  - 첫 묶음 6종: 헤비 디스토션, 파워 와우·부스트, 베이스 신스, 멀티밴드 컴프, 타이트 부스트, 파라메트릭 EQ.
  - 둘째 묶음 6종: 7밴드 EQ, 멀티 와우, 옥타브 퍼즈, 하이게인 2종, 피치 벤드.
  - 모두 Chimera 고유 모델이며 원본 하드웨어와 같다고 주장하지 않습니다.
- **신호 순서:** PRE·POST 순서를 정해진 범위 안에서 바꾸고 저장·Undo합니다. 순서를 바꿀 때 클릭이 나지 않습니다. PRE 보드와 ROUTING 그래프에서는 끌어서 순서를 바꿀 수 있습니다.
- **AMP 확장:** 레퍼런스 앰프 5종과 3밴드 새추레이션을 추가합니다.
- **POST 확장:** BUS COMP·PREAMP·EQUALIZER 9종과 MODULATION·DELAY·REVERB 9종을 추가합니다. 2-필터 모듈레이션과 확장 모듈레이션 라우팅도 추가합니다.
- **CREATIVE:** 창작용 이펙트 9종을 추가합니다.
- **SYNTH:** 입력 음정을 따라가는 신스 페이지를 추가합니다.
  - 엔진 3종, 오실레이터 3개, 샘플 모드, 모드 매트릭스, 4곳의 삽입 위치를 제공합니다.
  - 외부 사이드체인 입력과 별도 SYNTH 출력 버스를 제공합니다.
  - 음정 추적은 합성 신호로 검증했으며 실제 연주 수용은 아직입니다.
- **Room:** 공간 크기·Send·흡음(Room Core)과 실내 조건·공간 배치(Room Advanced)를 제공합니다. 룸 배경은 Space 재질을 따릅니다.

### 다이내믹스와 출력

- **멀티밴드:** 독립 6밴드 다이내믹스, 스테레오 링크·M/S를 제공합니다.
- **출력:** Studio true-peak 출력 리미터와 LUFS·true-peak 미터를 추가합니다. Live 샘플 피크 리미터는 그대로 있습니다.
- **OVERSAMPLING Auto:** 새 인스턴스의 기본값입니다. 호스트 샘플레이트에 맞춰 배율을 고릅니다. 기존 프로젝트는 저장된 배율을 유지합니다.

### Graphical EQ

- 여러 밴드를 선택하고 그룹으로 편집합니다(Ctrl/Cmd+클릭, 박스 선택, Ctrl/Cmd+A). 삭제는 한 번의 Undo로 되돌립니다. 비동기 메뉴와 선택 전환을 보호합니다.
- 노드를 Shift로 미세 조정하고, Alt로 한 축만 움직입니다.
- 표시 범위(±6/12/24 dB), 커서 표시, 저역 확대, 애널라이저 기울기와 PEAK hold를 추가합니다.
- **밴드 SOLO:** SOLO 버튼이나 가운데 버튼을 누르고 있는 동안 그 밴드만 들립니다. 녹음과 오프라인 바운스에는 적용되지 않습니다.
- **EQ별 A/B:** Tone EQ와 Final EQ가 각각 A/B 곡선을 갖습니다. 다른 EQ로 곡선을 복사할 수 있습니다.

### Auto Set

- 입력·게이트·Tone EQ·컴프·멀티밴드·De-esser·리미터에 앰프·캐비닛·부스트·공간계·Dual/Matrix 단계를 더했습니다. 단계별 잠금, 강도, UNDO AUTO를 제공합니다.
- **새 단계:**
  - Dual/Matrix 레인 극성. 20 Hz부터 판정하고, 대역별 반대와 지연은 반전하지 않습니다.
  - 딜레이 템포 동기화.
  - 팩토리 IR 선택. 저역 기본음을 지킵니다.
- **기본으로 꺼진 단계:**
  - 앰프 채널 선택.
  - 앰프 INPUT TRIM.
- **악기 판별:** 입력에서 기타·베이스·보컬·건반·드럼을 판별해 표시합니다. 보컬·드럼일 때 앰프·캐비닛 단계를 건너뛰는 옵션도 있으며, 기본으로 꺼져 있습니다.

### 편의 기능과 플랫폼

- **Easy view:** 프리셋, 노브 6개, Auto Set, 튜너만 있는 간단한 시작 화면을 추가합니다. 기존 화면은 *full editor*로 그대로 쓸 수 있습니다.
- **A/B MATCH:** 두 슬롯의 출력 크기를 맞춰 비교합니다. 플러그인 출력 자체를 바꿉니다. 녹음·렌더 중에는 적용되지 않습니다.
- **CAB:** 리그의 캐비닛을 WAV IR로 내보냅니다. AVX를 쓸 수 있는 CPU에서는 캐비닛 연산이 빨라집니다. 리콜할 때 음소거 시간이 짧아지고, 다음 리콜에 쓸 응답을 미리 준비합니다.
- **Doubler:** 낮은 기본음을 보호합니다. 모노로 합쳤을 때의 콤 필터링을 측정해 둡니다.
- **Standalone:** 장치 진단을 제공합니다. Windows에서는 첫 실행 때 ASIO를 우선 선택합니다. 입력이 음소거된 이유를 안내합니다.
- **OBS 필터:** Windows, macOS(Universal, 12 이상), Linux에서 Chimera 편집기 창과 설치기를 제공합니다. 설치기는 사용자 데이터를 보존합니다. 실제 OBS 앱에서 상태 복원, 다중 필터, 1시간 녹화, 포맷, 지연, 출력 일치를 시험합니다.
- **SETTINGS:** 베타 만료 시각(KST)과 정확한 남은 시간을 표시합니다. 베타테스터 코드를 입력할 수 있습니다(HMAC 방식).

## 업데이트와 기존 프로젝트

Chimera와 DAW를 종료한 뒤 설치합니다. 설치 후 SETTINGS에서 **1.4.0-beta.1**과 build 값을 확인합니다.

- **유지되는 것:** 플러그인 식별자, 기존 파라미터 순서와 자동화 매핑, 개인 프리셋·IR 저장 경로는 그대로입니다.
- **새 파라미터:** 끝에 추가됩니다. 저장된 프로젝트를 열면 새 기능은 꺼진 상태나 이전과 같은 소리로 열립니다.
- **기본값이 바뀐 것:** 새 인스턴스에서만 바뀝니다. 대표적으로 OVERSAMPLING Auto가 있습니다.

## 만료

이 버전은 **2027-05-31T14:59:00Z / 2027-05-31 23:59:00 KST**에 만료됩니다. 14일 전부터 경고합니다.

- 이미 열려 있는 인스턴스는 만료 후에도 계속 소리를 냅니다.

- 인증된 베타테스터 코드는 그 컴퓨터의 만료를 무기한 해제합니다(SETTINGS → Enter beta tester code...).

## 알려진 한계

- **청음과 실제 장비:** 실제 기타·베이스 DI 청음, Studio One 등 실제 DAW와 오디오 장치 수용, 공개 서명·macOS 공증은 아직입니다. Drop A 기타·베이스 실제 녹음도 아직 확보하지 못했습니다.
- **Transpose:** 실시간 Transpose 두 검사는 계속 보류합니다(I2.PITCH_LIVE, I2.PITCH_DI).
- **AAX:** 개발 빌드만 있습니다. 실제 서명과 Pro Tools 수용 전까지 배포하지 않습니다.
- **Auto Set 임계값:** 각 단계의 임계값은 합성 신호로 정한 시작값입니다. 실제 리그에서는 단계마다 잠금으로 현재 설정을 유지할 수 있습니다.
- **Auto Set 악기 판별:** 기본값은 판별 결과를 표시만 하는 것입니다. 검증 전까지는 Guitar/Bass를 직접 고르는 방법을 권장합니다.
- **NAM 모델:** Náströnd·Niflheimr NAM 모델은 Chimera 패키지에 들어가지 않습니다.
