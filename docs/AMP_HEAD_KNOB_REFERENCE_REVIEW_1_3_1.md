# Amplifier knob hardware reference review — 1.3.1

Reviewed 11 October 2026. Baseline: `d8e5caf3bd391ea794d4604a8feff36f248d8a2d`.

The user requested a complete review after the Niflheimr size correction. All 26 catalog heads (25 active plus the recallable retired Iron Compact) were inspected in the existing Windows native captures. The preceding renderer varied material on a largely shared round body; several hardware families therefore had incorrect silhouettes, cap/pointer contrasts or proportions.

## Scope and implementation

- Compare actual downloaded manufacturer photographs, parts photographs and manuals. For discontinued models, use identified firsthand specimen photographs and record the version limitation below. Images were inspected directly; search-result image placeholders and black-and-white diagrams alone were not accepted as color evidence.
- Recreate the observed hardware language in native procedural controls: skirt, bell, knurled cylinder, scalloped collet, projecting pointer and raised bar. Keep fixed lighting, sidewalls and contact/cast shadows. Source photographs are reference evidence; they are not shipped assets or Chimera screenshots.
- Modern Bass selects B7K and DB751 knob families by its existing control key. Mark IV Output and Rockerverb MKIII EQ retain observed size hierarchy; the enlarged control renderer protects the preceding 30 px drawing-area floor. Hit targets remain unchanged.
- Correct 14 model-specific diameters and row placements; retain the other 12, including the recent Niflheimr proportion fix. Existing plate boundaries remain independent and unchanged.
- Preserve parameter IDs, ranges, channel masks, automation, recall, transient numeric readouts and source enclosure artwork. The shared renderer applies to enlarged, compact, room and focused-CAB views.
- Visual review caught transient value backgrounds extending across the trim on Modern Bass, Orange Crown and Metro Clean. Centre a stable readout/editor rectangle sized for the formatted range and editing padding; retain the full parameter-name cell. The layout contract now checks the entire readout rectangle, not only its glyphs.
- Match the B7K raised grip's width to the inspected hardware (about half its round base), independently of ZUTA's narrower bar.

## Evidence limits and deliberate adaptations

- Gallien-Krueger 800RB: archived product photograph plus manufacturer service material; exact specimen year is unresolved.
- VOX AC30: catalog does not name a year; black chickenhead Custom/Top Boost language is selected.
- Orange Rockerverb: MKIII-labelled front/angle/rear photographs support the barrel shape and larger main/smaller EQ controls. A MKII photograph was excluded. The bright dot is a Chimera readability adaptation; the photographed OEM marker could not be resolved reliably.
- Matchless DC-30: inspected RV specimen supplies the cream chickenhead reference; its extra Reverb control is not added.
- Dumble ODS: current official blackface photographs show black chickenheads. Historical versions vary; no universal ODS hardware claim is made.
- SUNN Model T: 1973 firsthand technician photographs support the black skirt and small silver center; current reissue parts are not substituted.
- Bogner Uberschall: a photographed Rev Blue specimen supplies the black chickenhead reference; exact production year remains unresolved.
- Liquid Lead: the real Mark IV GEQ is a slider bank. Existing Chimera rotary GEQ controls remain an intentional UI adaptation.
- Fixed hardware scale numerals are simplified to restrained marks; changing parameter values appear only while adjusting or entering a value.
- Material names describe rendered appearance; no material composition or physical knob dimensions were measured.

## Validation boundary

The unchanged 26-model / 61-channel / four-size layout contract and native interaction contract must pass on this source. Added focused visual regressions exercise actual Modern Bass per-key widget differentiation, cross-profile cache reuse, fixed round-cap lighting and rotating grip containment. The cache remains bounded to 32 MiB and releases native images with its last live owner.

Software snapshots are intermediate rendering evidence. Only exact-source CI captures attached to native peers count as native component evidence. Studio One operation, OS DPI coverage and full product acceptance remain separate. PR #44 records the exact final source, CI run and artifact digests after verification.
